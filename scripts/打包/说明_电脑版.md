# 研海寻踪 · 电脑版

双击 `研海寻踪.exe` 就会启动。窗口里会打出一行 `本机打开：http://127.0.0.1:8766/`，
浏览器通常会自动打开界面；没自动开，把那个网址复制到浏览器里就行。

第一次打开会让你建一个账号（邮箱 / 称呼 / 密码），建完直接进入工作台。
这个账号只存在这台电脑上，不需要联网注册。

## 数据放在哪

程序旁边会自动生成一个 `用户数据\` 文件夹，账号、项目、关系决定、图谱版本都在里面的
`yanhai.sqlite3`。换电脑时把 exe 和这个文件夹一起拷过去，账号和项目都在。

装在 `C:\Program Files` 这类写不进去的地方时，数据会改放到 `%LOCALAPPDATA%\研海寻踪\`。

## 怎么关

关掉那个黑色窗口，服务就停了。浏览器的标签页可以留着，下次启动地址不变。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| Windows 提示"未知发布者" | 点「更多信息 → 仍要运行」。这个程序没有代码签名证书 |
| 浏览器打开是空白或打不开 | 看窗口里打出来的端口是不是 8766，被占用时程序会自动往后换一个 |
| 想换端口 | `研海寻踪.exe --port 9000` |
| 杀毒软件报拦截 | 单文件程序启动时会先把内容解到临时目录，有的杀毒软件会拦，加信任即可 |
| 想看服务有没有起来 | 窗口里出现"已启动"就是起来了；也可以开 `http://127.0.0.1:8766/api/health` |

## 手机上也想用

看手机版那个包（`研海寻踪-V3.1-手机版.zip`）。两个包里的 exe 是同一份，
区别只是手机版那个包里带了一个用 `--lan` 启动的快捷脚本和手机端的说明。
