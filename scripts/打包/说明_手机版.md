# 研海寻踪 · 手机版

手机跑不动这套东西，所以做法是：**电脑上跑服务，手机用浏览器把它装到主屏幕**。
电脑和手机要连同一个 WiFi。

## 三步

1. 电脑连上 WiFi，双击 `启动手机版.bat`（等同于 `研海寻踪.exe --lan`）。
2. 窗口里会打出 `手机打开：http://192.168.x.x:8766`。手机连**同一个** WiFi，用浏览器打开这个网址。
3. 存到主屏幕：
   - iPhone（Safari）：底部「分享」按钮 →「添加到主屏幕」；
   - 安卓（Chrome）：右上角「⋮」→「添加到主屏幕」或「安装应用」。

之后从桌面图标点进去就是全屏的，没有地址栏，跟装了一个 App 一样。

## 账号

第一次打开会让你建账号（邮箱 / 称呼 / 密码），建在电脑这边——
数据都在电脑的 `用户数据\` 里，手机只是一个入口。同一个账号在电脑和手机上都能登。

## 打不开时按这个顺序查

1. 手机和电脑是不是同一个 WiFi？有的路由器把 2.4G 和 5G 分成两个网络，会互相看不见。
2. 网址里的 IP 和端口，和电脑窗口里打出来的是不是完全一致。
3. Windows 防火墙有没有拦这个程序——第一次运行时通常会弹窗，选「允许访问」。
4. 电脑上那个黑色窗口还开着吗？关掉窗口服务就停了。

## 这份是"装到主屏幕"，不是应用商店的安装包

真正的安卓 APK 需要 Android SDK 与签名证书，iOS 的 IPA 需要 macOS、Xcode 与开发者证书，
这次都没有，也不该为了凑一个安装包去伪造。装到主屏幕之后的使用体验是一样的：
全屏、独立图标、和浏览器标签页分开；差别是它不会出现在应用商店里。

另外，手机在局域网里断网时打不开数据：界面外壳能看到（浏览器缓存过的话），
但项目、证据、图谱每次都要连回电脑上的服务——这些内容不缓存在手机上，
否则会看到过期的结论。
