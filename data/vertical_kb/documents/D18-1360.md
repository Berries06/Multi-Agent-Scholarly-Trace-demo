# SciERC and SciIE

## Problem
Scientific information extraction addresses scientific knowledge graph construction.

## Dataset
SciERC benchmarks scientific information extraction.
SciERC benchmarks entity extraction.
SciERC benchmarks relation extraction.
SciERC contains entity extraction, relation extraction, and coreference annotations.

## Method
SciIE uses contextualized span representations.
SciIE supports scientific knowledge graph construction.

## Limitation
Sentence-only extraction misses cross-sentence relations.
