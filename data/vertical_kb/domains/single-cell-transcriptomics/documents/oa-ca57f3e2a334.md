# ArchR is a scalable software package for integrative single-cell chromatin accessibility analysis

## Method
Here we present a software suite for single-cell analysis of regulatory chromatin in R (ArchR; https://www.archrproject.com/ ) that enables fast and comprehensive analysis of single-cell chromatin accessibility data.

## Evaluation
