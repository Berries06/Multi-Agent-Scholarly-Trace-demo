# Squidpy: a scalable framework for spatial omics analysis

## Method
Here, we present Squidpy, a Python framework that brings together tools from omics and image analysis to enable scalable description of spatial molecular data, such as transcriptome or multivariate proteins.

## Evaluation
Spatial omics data are advancing the study of tissue organization and cellular communication at an unprecedented scale.

## Finding
Here, we present Squidpy, a Python framework that brings together tools from omics and image analysis to enable scalable description of spatial molecular data, such as transcriptome or multivariate proteins.
