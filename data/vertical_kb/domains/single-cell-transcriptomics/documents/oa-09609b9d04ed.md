# A large-scale binding and functional map of human RNA-binding proteins

## Method
Here we introduce a new data set of RNA elements in the human genome that are recognized by RNA-binding proteins (RBPs), generated as part of the Encyclopedia of DNA Elements (ENCODE) project phase III.

## Evaluation
Here we introduce a new data set of RNA elements in the human genome that are recognized by RNA-binding proteins (RBPs), generated as part of the Encyclopedia of DNA Elements (ENCODE) project phase III.
We describe the mapping and characterization of RNA elements recognized by a large collection of human RBPs in K562 and HepG2 cells.

## Finding
These data expand the catalogue of functional elements encoded in the human genome by the addition of a large set of elements that function at the RNA level by interacting with RBPs.
