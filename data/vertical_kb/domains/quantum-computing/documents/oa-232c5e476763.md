# Efficient Variational Quantum Simulator Incorporating Active Error Minimization

## Method
A new proposal uses a classical-quantum hybrid scheme to implement simple error-tolerant quantum processors with relatively few resources.

## Evaluation
Quantum computers will need to be tolerant to errors introduced by noise, but current proposals estimate that the number of qubits required for error correction will be many orders of magnitude larger than the number.
