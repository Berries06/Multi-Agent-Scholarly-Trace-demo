# Demonstration of a quantum error detection code using a square lattice of four superconducting qubits

## Method
Here we present a quantum error detection protocol on a two-by-two planar lattice of superconducting qubits.

## Evaluation
Whilst classical bit-flip detection can be realized via a linear array of qubits, a general fault-tolerant quantum error-correcting code requires extending into a higher-dimensional lattice.
Here we present a quantum error detection protocol on a two-by-two planar lattice of superconducting qubits.

## Finding
Whilst classical bit-flip detection can be realized via a linear array of qubits, a general fault-tolerant quantum error-correcting code requires extending into a higher-dimensional lattice.
This result represents a building block towards larger lattices amenable to fault-tolerant quantum error correction architectures such as the surface code.
