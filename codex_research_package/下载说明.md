## 为什么保留失败记录

`download_manifest.csv` 同时保留成功与失败任务，可避免以后重复尝试已知受限 URL，也使资料采集过程可审计。若网站访问策略变化，可重新运行：

```powershell
uv run python download_resources.py
```

脚本会跳过已通过校验的文件，只重试失败项。
