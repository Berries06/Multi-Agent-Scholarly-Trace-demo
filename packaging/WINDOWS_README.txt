研海寻踪 Windows Qt 验证版
==========================

运行环境：Windows 10/11 x64
启动方式：解压整个目录后，双击 YanhaiTrace.exe

说明：
1. 离线 Mock 无需联网或 API Key。
2. DeepSeek、GPT、Claude、Kimi 实时模式需要联网并由用户临时输入 API Key。
3. API Key 仅保存在当前进程内存中；程序不会把它写入文件。
4. 这是功能验证发行包，没有安装器、自动更新和代码签名。Windows SmartScreen
   可能显示未知发布者，请仅从 snowsong.top 下载并核对 SHA-256。
5. 解压后不要只复制 exe；同目录内的 _internal 文件夹是运行所必需的。

项目版本：0.2.0
