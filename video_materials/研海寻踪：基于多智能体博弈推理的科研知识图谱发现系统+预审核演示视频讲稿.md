# “研海寻踪”预审核演示视频讲稿

> 建议成片时长：4 分钟左右  
> 画面规格：1920×1080，横屏，录屏区域只保留 Demo 与必要的标题页  
> 口径原则：只陈述当前版本已经实现和可复核的内容；“计划接入”“下一阶段完成”的能力不得说成已经完成。

## 一、4 分钟主讲稿与分镜

### 0:00—0:15　开场：作品与问题

**画面**：作品名称页，随后切换到 Demo 首页。

**讲稿**：

大家好，我们的作品是“研海寻踪：基于多智能体博弈推理的科研知识图谱发现系统”。项目面向科研文献碎片化、证据分散和跨学科理解困难的问题，希望把“搜索论文”升级为“沿着可追溯证据理解技术脉络，并形成可验证的研究假设”。

### 0:15—0:45　榜单要求与总体思路

**画面**：Demo 首页依次指向三个垂直领域、三组学习者画像和协同推理入口。

**讲稿**：

围绕榜单对垂直领域知识库、差异化学习者画像、多智能体协同中间数据和个性化输出的要求，我们构建了科学信息抽取、材料发现与图神经网络、教育知识追踪三个领域切片，每个领域收录三十篇可检索论文记录；系统准备了三组差异化学习者画像，并形成九组完整的“输入—协同轨迹—个性化输出”样例。

### 0:45—1:20　核心一：论文信息抽取与可信建图

**画面**：选择一个领域和学习者画像，点击“启动协同推理”；展示知识抽取统计、证据跨度和图谱节点。

**讲稿**：

论文进入系统后，先被转换为带论文、章节、句子和字符偏移的统一证据对象。论文知识抽取 Agent 从证据片段中提出方法、任务、数据集、指标、发现和局限等实体，以及“使用、解决、评测于、支持、矛盾”等关系候选。候选实体经过规范化和别名合并，但只有能够绑定论文编号和证据跨度的关系，才有资格进入后续裁决。当前 Demo 共管理九十篇论文记录，其中十九篇形成证据卡，抽取一百零八条证据跨度、六十六个规范实体和九十一条候选关系；其余只有元数据的记录只用于书目检索，不被包装成全文证据。

### 1:20—1:55　核心二：三智能体异质裁决

**画面**：依次滚动“提出者—批判者—裁判”轨迹；停留在一条被接收和一条被拒绝或转复核的关系上。

**讲稿**：

关系是否入图，由三个核心决策 Agent 完成。提出者负责组织候选命题与依据；批判者检查实体类型、关系方向、证据语义、绝对化措辞和单一来源风险；裁判依据独立规则输出接收、转人工复核或拒绝。这里的创新不在于堆叠 Agent 数量，而在于用异质职责制造可检查的反证信号，让系统能够保留不确定性，而不是强行回答所有问题。

### 1:55—2:35　核心三：意图驱动的图检索与个性化输出

**画面**：展示意图识别、`graph_breadth`、`graph_depth`、`hybrid_drift` 路由，再展示知识图谱、技术脉络和个性化资源。

**讲稿**：

用户意图感知 Agent 会把查询分为文献检索、分析推理和 Idea 发现。检索型问题采用图广度搜索，强调覆盖与多来源；分析型问题采用图深度搜索，返回可审计的实体、关系和证据路径；Idea 型问题采用混合漂移策略，从知识社区进入局部关系并寻找缺失边、弱连接和争议。系统基于同一可信图谱，为本科入门学习者、跨学科硕士和企业技术情报人员生成不同深度的导读、复现实操、分阶测评和待验证 Idea。

需要特别说明：当前运行的是受 Microsoft GraphRAG 启发的离线图检索基线，而不是微软官方 GraphRAG 运行时；下一阶段将导出标准图数据，对比 Local、Global 和 DRIFT 查询。

### 2:35—3:20　对照与消融：为什么需要异质多智能体

**画面**：切换到消融实验图表，依次指向 E0、E1、E2、E3；随后展示失败案例。

**讲稿**：

为了验证多智能体的实际价值，我们固定同一组二十四条压力命题，只改变决策机制。普通规则程序的接收精确率为百分之五十，不支持命题接收率，也就是 UAR，为百分之百；单次判定和同质三路投票的结果相同，接收精确率为百分之六十一点一，UAR 为百分之六十三点六；提出者—批判者—裁判机制的接收精确率达到百分之八十四点六，UAR 降至百分之十八点二，同时保持百分之八十四点六的 Gold 召回。相较最强单次基线，精确率提高二十三点五个百分点，UAR 降低四十五点四个百分点。

这只是开发可见的小样本压力测试，不代表公开基准领先。系统仍展示两条错误接收和两条转复核的真实失败案例，便于后续补充自然语言推断、证据充分性模型和人工复核。

### 3:20—3:45　工程可靠性与交付

**画面**：展示健康状态、运行日志或首页“离线演示就绪”；快速展示压缩包中的 `RUN_DEMO.bat`。

**讲稿**：

Demo 支持离线运行，后端加入请求超时、有限重试、幂等键、熔断、有界任务队列、健康检查和结构化日志。接收方解压后双击 `RUN_DEMO.bat` 即可启动，并通过本地地址访问；当前有效验收链路六十六项自动化测试全部通过，零失败。

### 3:45—4:05　总结与边界

**画面**：回到知识图谱与作品名称页。

**讲稿**：

因此，“研海寻踪”目前完成的是从领域论文切片、证据跨度抽取、异质三智能体裁决，到意图驱动图检索和个性化资源生成的可运行闭环。它的核心价值，是让每条科研关联能够回到证据、让错误能够被批判、让 Idea 明确标注为待验证。下一阶段我们将优先完成合法全文 Pilot、双人标注金标准、候选模型主实验和真实用户试点。谢谢各位专家老师。

## 二、90 秒备用精简稿

大家好，我们的作品是“研海寻踪：基于多智能体博弈推理的科研知识图谱发现系统”。项目针对科研文献碎片化、证据分散和跨学科理解困难，把论文转化为可追溯的科研知识图谱。

当前 Demo 建有三个垂直领域，每个领域三十篇论文记录，并提供三组学习者画像和九组完整输入输出样例。论文知识抽取 Agent 先识别方法、任务、数据集、指标、发现和局限等概念，并把关系绑定到论文、句子和字符跨度。随后，提出者组织候选，批判者寻找类型、方向和证据问题，裁判决定接收、复核或拒绝。用户意图感知 Agent 再把检索、分析和 Idea 查询分别路由到图广度、图深度和混合检索，生成论文推荐、技术脉络、争议提示和个性化学习资源。

在固定二十四条压力命题的对照中，三智能体机制的接收精确率为百分之八十四点六，不支持命题接收率为百分之十八点二；相较最强单次基线，精确率提高二十三点五个百分点，UAR 降低四十五点四个百分点。该结果属于开发可见的小样本机制验证，我们同时保留错误案例和置信区间，不将其表述为公开基准领先。

Demo 可离线双击运行，并加入超时、重试、幂等、熔断、日志和健康检查。“研海寻踪”的亮点不是堆叠 Agent，而是让每条关联可回到证据，让错误可被批判，让科研 Idea 明确保持待验证。谢谢。
