# 五层系统架构

## 1. 数据层
- 文献接入：支持标题、摘要、关键词、年份、来源。
- 清洗处理：去重、分句、元数据标准化。
- 输出：统一文献对象（Document）。

## 2. 理解层
- 术语标准化：同义术语映射（ontology）。
- 信息抽取：实体、关系、方法/假设/结论结构化。
- 输出：候选命题（Claim）与证据（Evidence）。

## 3. 博弈推理层（提出者-批判者-裁判）
- 提出者：生成跨文献候选关联。
- 批判者：检验证据充分性、冲突性与迁移条件。
- 裁判：融合支持与反证，给出最终置信度与保留意见。
- 输出：带争议状态的命题。

## 4. 图谱层
- 节点：实体（方法、任务、指标、领域概念）。
- 边：支持（support）、冲突（conflict）、演化（evolve）。
- 特性：时序属性、证据回溯、置信度过滤。

## 5. 应用层
- 演化溯源：按时间轴追踪技术演进。
- 争议捕获：聚焦冲突边与高争议子图。
- 蓝海发现：依据图拓扑缺口推荐方向。
