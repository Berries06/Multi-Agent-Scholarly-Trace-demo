# CAMEL 学习总结（2026-07-22）

## 今日完成
- 在 Windows 环境使用 `uv` 成功搭建 Python 虚拟环境并安装 `camel-ai`。
- 解决了安装中的依赖冲突与网络下载问题（通过镜像源稳定安装链路）。
- 正确配置 `.env`（API Key、Base URL）并完成调用验证。
- 跑通了 CAMEL 多智能体流程（Planner / Executor / Reviewer）。

## 核心收获
1. **先最小可用，再逐步扩展**
   - 先安装基础包 `camel-ai`，避免一开始使用 `[all]` 引发依赖冲突。
2. **环境稳定性优先**
   - 使用 `uv + venv` 保证依赖隔离；使用镜像源提升安装稳定性。
3. **配置与代码分离**
   - 通过 `.env` 管理密钥与接口地址，避免把敏感信息写入代码或终端历史。
4. **多智能体比单轮问答更适合复杂任务**
   - 通过“规划-执行-审查”的角色分工，输出更结构化、可落地。

## 遇到的问题与解决
- **问题：** `camel-ai[all]` 安装冲突
  - **解决：** 改为先装 `camel-ai` 基础包。
- **问题：** TLS/下载失败
  - **解决：** 切换到稳定镜像源后重试。
- **问题：** 模型名与框架枚举不一致
  - **解决：** 使用当前版本 CAMEL 已支持的模型枚举先跑通主流程。

## 方法论沉淀
- 先验证链路（安装/调用）→ 再做功能（多 Agent）→ 最后做优化（日志、导出、展示）。
- 以“可运行结果”为里程碑，而不是一次性追求全功能。
