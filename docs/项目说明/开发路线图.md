# 竞赛推进路线图

## 阶段 A：可运行基础版

- 固化赛题映射、数据协议和 Agent 职责；
- 跑通三组画像到三类资源的闭环；
- 做出可视化智能体轨迹、图谱和学习报告；
- 建立可重复运行的工程评测与单元测试。

## 阶段 B：真实知识与模型接入

- 选择 1 个主垂直切片，建议“多智能体科研推理与可信 RAG”；
- 合法获取 100-300 篇论文的元数据、摘要和关键证据句；
- 建立领域本体、关系标注规范和专家复核流程；
- 按 Hello-Agents 的轻量框架思路定义统一消息、模型 Provider 和可观测轨迹；
- 接入 CAMEL/LLM，使用 `RolePlaying` 验证角色协作，并强制结构化输出和引用约束；
- 增加研究计划、证据笔记和 SSE 进度，形成可追踪的 Deep Research 链路；
- 实现反证检索与多轮辩论终止条件。

## 阶段 C：评测与消融

- 已完成：独立实验目录、mock case、单因素预设、鲁棒性与工作负载脚本；
- 已完成：原始 JSON、CSV、汇总 JSON、Markdown 报告自动产出；
- 建设不少于 50 组画像-任务-资源金标准；
- 对比单 Agent、普通 RAG、多 Agent 无批判、多 Agent 完整版；
- 测量幻觉率、引用正确率、覆盖率、适配准确率、时延和成本；
- 让领域专家盲审，并保存原始评分表。

## 阶段 D：参赛交付

- 作品设计实现方案；
- 10 分钟以内演示视频；
- 答辩 PPT 和 3 分钟备用极速演示；
- 源码、可执行程序、部署说明、测试数据和单元测试；
- 数据合规说明、开源许可证清单；
- 软著/专利材料与查新记录。

## 近期优先级

1. 定义统一 `AgentMessage`、`AgentResult`、`ResearchPlan` 和 `EvidenceNote`。
2. 用真实摘要替换当前人工摘要，并完成第一轮专家关系标注。
3. 接入可配置 LLM/CAMEL 适配器，同时保留离线规则 Provider。
4. 完成 50 组测试数据，并扩充准确性、效率、鲁棒性、协作性评测。
5. 用人工金标准替换 mock 数据，验证现有消融是否带来真实收益。
6. 将现有时序、争议与蓝海启发式模块升级为真实论文图谱算法。
