# 10 分钟演示脚本

## 0:00-0:50 痛点与定位

展示首页并说明：传统检索只给出文献列表，无法回答“不同背景的人下一步该学什么、哪些结论可信、哪些方向值得继续验证”。研海寻踪把科研知识图谱转化为个性化科研训练底座。

## 0:50-2:00 差异化画像

先选择本科生林晓，展示知识图谱、多智能体和证据评估得分较低；再指出系统不会给所有人同一份摘要，而会先确定难度与盲区。

## 2:00-4:20 多智能体协同

点击“启动协同推理”，依次解释：

1. 学情诊断 Agent 定位盲区；
2. 证据检索 Agent 召回真实 arXiv 文献；
3. 提出者生成候选关联；
4. 批判者检查来源、单一证据与绝对化表述；
5. 裁判按证据完整性定标；
6. 资源 Agent 只使用通过裁决的命题。

重点展示“多智能体辩论 guarantees 零幻觉科研结论”被拒绝，证明系统不是简单堆叠 API。

## 4:20-5:50 知识图谱与溯源

展示文献节点、概念节点、结论节点及 evidence 边。点击或口头指出 arXiv ID，说明每条进入资源的结论都能回到来源。

## 5:50-7:30 三类个性化资源

依次切换：

- 定制导读：与当前难度匹配的概念解释；
- 复现实操：从问题拆解到消融实验的步骤；
- 分阶测评：基础、应用、挑战题。

同时展示蓝海假设被明确标为“待验证”，不会混入已证实知识。

## 7:30-8:30 动态反馈

点击“太难，降维解释”，展示目标难度、匹配分和解释策略变化。切换到企业分析师画像，说明同一知识库可以生成指标与风险导向的训练路径。

## 8:30-9:20 量化评测

展示三个指标及口径：

- 幻觉率代理；
- 画像适配准确率；
- 核心知识点覆盖率。

必须主动说明当前是工程回归指标，正式参赛结果将来自 50 组以上专家标注数据和盲审。

## 9:20-10:00 创新与落地

总结三点：

1. 提出、反证、裁决拥有不同目标，不是重复生成；
2. 图谱参与检索、路径和资源生成，不只是展示；
3. 全链路可回放、可溯源、可反馈。

最后给出高校科研训练和企业技术情报两个落地场景。
