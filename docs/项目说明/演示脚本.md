# 10 分钟演示脚本（v2，对齐 React 产品界面与新资产）

> 原则：只演示"真实存在且可复现"的东西；每个数字当场给出出处；
> 不写"零幻觉"，只写"护栏 + 实测"。镜头顺序即评分顺序（完整→创新→体验→实用）。

## 0:00-0:50 痛点与定位（完整性引子）

首页（React 界面，左侧边栏"产品演示/实验台"）。一句话：传统检索只给文献列表，
研海寻踪把"论文原文 → 证据图谱 → 三智能体裁决 → 个性化学习资源"做成一个可追溯闭环。

## 0:50-1:40 多领域知识库 + 差异化画像

- 领域选择器切换 3 个领域（30 篇检索记录/领域，其中证据卡 8+5+6 篇）；
- 画像下拉切换 3 组（本科/跨专业研究生/企业分析师），点开画像雷达图；
- 说明：不同画像 → 不同难度与盲区，绝不千人一面。

## 1:40-3:20 多智能体调度可视化（创新性核心镜头）

输入问题 → 提交 → 展示「思考过程 · 5 个 Agent」时间线：

1. 论文知识抽取（复用版本化索引，输出证据跨度数）；
2. 用户意图感知（识别检索/分析/Idea 并显示路由）；
3. 提出者 → 批判者 → 裁判：逐条命题展示批判项与裁决理由。

**必讲的两条设计原则**：
- 异质分工（提出者保召回、批判者找错、裁判独立校准），不是同模型投票；
- **模型无关护栏**：当场输入"多智能体辩论 guarantees 零幻觉"→ 无证据+绝对化 →
  被强制拒绝。说明"防幻觉不依赖模型自觉"。

## 3:20-4:30 证据链溯源（体验 + 溯源）

- 切到「证据知识图谱」力导向图：论文（蓝）→ 证据跨度（绿）→ 实体（橙）→ 关系边；
- 点击任一证据节点：弹出章节 + 字符跨度；点击关系边显示 evidence_ids；
- 说明：资源里每个论断都带 evidence_ids，可回到论文原句——高保真溯源是结构不是口号。

## 4:30-5:30 语义力度校验（差异化创新，理论锚点）

- 演示批判者六查里的"时态/体"检查：输入"作者正在尝试改进 X"→ 系统标注
  "进行时≠已完成（未完成体悖论）"，拒绝把它当成功结论；
- 口头带一句理论依据：ACL 2026《The Imperfective Paradox in Large Language Models》；
- 这一镜头是"细节上有文献根基的防幻觉创新"，多数作品没有。

## 5:30-7:00 个性化资源 + 动态反馈

- 展示导读/实操/测评：**测评题是从 accepted 图谱三元组动态生成的**（关系类型题、
  实体类型题、证据溯源题），不是写死题库；
- 点击"太难"→ 难度档与解释策略变化（动态迭代闭环）；
- 蓝海 Idea 明确标"待验证假设"。

## 7:00-8:00 消融高潮（证明机制有效）

- 展示对比实验框架：同候选池四组机制（普通规则 / 单次判定 / 同质投票 / 三智能体）；
- 指表：三智能体把"不支持命题接收率"从 100% 压到 18.2%（附 Wilson 区间）；
- 声明口径：这是合成压力池初筛；真实模型对比（多厂商 10 模型）已就绪待跑，
  结论将在 140 条 L2 用例 + 人工核验锚点上重测。

## 8:00-9:00 测试数据与成本（实用价值）

- 展示 140 条 L2 真实证据机制用例（28 正 + 112 负，SHA-256 冻结）与 L3 抽查表；
- 展示成本账本字段（每 Agent 的 token/耗时/成本，多模型价目表）；
- 声明：三个硬指标（幻觉率/适配/覆盖率）将在冻结集 + 人工核验后给出带区间的实测值。

## 9:00-10:00 创新总结与落地

三点收尾：

1. **证据结构**：paper→evidence→entity→relation，关系必带原文跨度；
2. **模型无关护栏 + 语义力度校验**：防幻觉不靠模型自觉，且有语言学理论锚点；
3. **可复现纪律**：冻结压力集、成员出题实验台、消融、SHA-256 回执——AI 辅助科研也可审计。

落地场景：高校科研训练（研究生如何读论文/找空白）+ 企业技术情报（岗位技能培训）。
