# 10 分钟演示脚本

## 0:00-0:50 痛点与定位

展示首页并说明：传统检索只给出文献列表，无法回答“不同背景的人下一步该学什么、哪些结论可信、哪些方向值得继续验证”。研海寻踪把科研知识图谱转化为个性化科研训练底座。

## 0:50-2:00 差异化画像

先选择本科生林晓，展示知识图谱、多智能体和证据评估得分较低；再指出系统不会给所有人同一份摘要，而会先确定难度与盲区。

## 2:00-4:20 多智能体协同

点击“启动协同推理”，依次解释：

1. 学情诊断与学习规划 Agent 定位盲区、难度和路径；
2. 证据检索与知识图谱 Agent 检索本地知识库与联网来源；
3. 该 Agent 内部按需调用批判、辩论和反证策略；
4. 独立质量模块评分并决定命题是否准入；
5. 个性化教学与反馈 Agent 生成导读、实操、测评和问卷。
重点展示“多智能体辩论 guarantees 零幻觉科研结论”被非 Agent 质量模块拦截，说明准入标准独立于教学生成。

## 4:20-5:50 知识图谱与溯源

展示“方法或概念—作用关系—研究结果”的论文知识证据流；流线强弱对应证据可信度，点击任意证据流后，右侧展示论文标题和质量意见，说明每条进入资源的知识关系都能回到来源。

## 5:50-7:30 三类个性化资源

依次切换：

- 定制导读：与当前难度匹配的概念解释；
- 复现实操：从问题拆解到消融实验的步骤；
- 分阶测评：基础、应用、挑战题。

只有在增强方案且问题明确要求研究空白或研究假设时，才展示标为“待验证”的假设候选；普通问答不显示该模块。

## 7:30-8:30 动态反馈

点击“太难，降维解释”，展示目标难度、匹配分和解释策略变化。切换到企业分析师画像，说明同一知识库可以生成指标与风险导向的训练路径。

## 8:30-9:20 量化评测

展示三个指标及口径：

- 证据风险代理；
- 画像适配度；
- 画像知识覆盖。

必须主动说明当前是工程回归指标，正式参赛结果将来自 50 组以上专家标注数据和盲审。

## 9:20-10:00 创新与落地

总结三点：

1. 提出、反证、裁决拥有不同目标，不是重复生成；
2. 图谱参与检索、路径和资源生成，不只是展示；
3. 全链路可回放、可溯源、可反馈。

最后给出高校科研训练和企业技术情报两个落地场景。
