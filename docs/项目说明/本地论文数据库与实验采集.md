# 本地论文数据库与实验采集

## 目标

本模块把原有 JSON 种子知识库扩展为可长期积累的 SQLite 数据库，用于满足
垂直领域知识库切片、差异化学习者画像、协同决策中间数据和个性化学习资源
完整输入输出示例的验证要求。

数据库默认位于 `outputs/runtime/yanhai.sqlite3`。部署时应通过
`YANHAI_DATA_DIR` 把数据库放在代码目录之外，避免发布新版本时覆盖实验数据。

## 垂直领域路由

当前使用可审计的关键词路由，将问题和论文分别归入：

- 嵌入式系统与音频；
- 人工智能与多智能体；
- 教育与学习科学；
- 机器人与定位导航；
- 生物医学与健康；
- 能源与材料；
- 通用科研。

实时检索结果先进入本轮不可变证据快照，再按论文自身内容进入对应领域切片。
不会因为用户问题属于 ESP32，就把无关的多智能体论文写进 ESP32 切片。

后续可以增加领域，但稳定的 `domain_slug` 不应随意修改。需要更高精度时，
可以在保持存储协议不变的前提下替换 `DomainRouter`。

## 保存的数据

SQLite 目前包含：

| 数据 | 用途 |
| --- | --- |
| `users`、`auth_sessions` | 本地账号和登录会话 |
| `user_profiles` | 不覆盖历史的版本化学习者画像 |
| `papers` | 论文和官方文档元数据、摘要、来源与哈希 |
| `domain_slices`、`slice_papers` | 垂直领域知识库切片 |
| `research_sessions` | 用户问题、画像快照、模型配置与实验组 |
| `evidence_snapshots`、`snapshot_papers` | 本轮实际使用的冻结论文集合 |
| `answer_variants` | A、B、C、Full 或普通单次回答 |
| `hallucination_evaluations` | 本地或外部检测器结果 |
| `survey_responses` | 满意度、个性化、学习感、信任和复用意愿 |

密码使用 `scrypt` 加盐哈希。API Key 不进入数据库。论文全文只有在许可证允许
时才能保存；当前主要保存元数据、摘要、官方资料摘要、URL 和内容哈希。

Web 端必须登录后才能运行推理、查看历史、运行对照实验或提交问卷。公开注册由
`YANHAI_REGISTRATION_OPEN` 控制，默认关闭；本地组织实验时需显式设置为 `1`。
`GET /api/profiles` 在未登录时只返回 `auth_required`，登录后只返回当前用户画像。

登录用户可选择“免费 DeepSeek (Flash)”。该选项不保存或下发服务器 Key：
HTTP 服务在进程启动时从 `secret/DeepSeekAPI.txt` 读取 Key，并仅在服务端发起
DeepSeek 请求。用户自带的 DeepSeek、GPT、Claude、Kimi Key 仍只用于单次请求，
不写入 SQLite。

## 对照实验

第一版固定四组：

| 版本 | 预设 | 消融内容 |
| --- | --- | --- |
| A | `no_critic` | 批判者 |
| B | `no_judge` | 裁判 |
| C | `no_knowledge_tracing` | 动态学情 |
| Full | `full` | 不消融 |

四组必须使用相同论文顺序。服务器保存全部版本，但只随机展示一个版本给学习者，
避免比较答案造成顺序和学习迁移偏差。

当前本地采集 MVP 只允许离线 Mock 运行四组消融。实时模型尚未开放消融入口，
因为现有实时链路每次都会独立规划和检索；在实现“检索一次、冻结一次、四个
Prompt 变体共享证据”前，直接运行四次会污染实验。

## 幻觉与论文外推论

`EvidenceBoundaryEvaluator` 当前执行可复现的本地检查：

- 接受或复核命题是否引用冻结快照中的论文；
- 回答引用是否越过本轮论文集合；
- 无有效证据的事实命题数量；
- 明确标注为待验证的假设数量。

明确标记的研究假设不会直接算作幻觉。当前结果是工程代理指标，不能替代外部
检测商和人工核验。外部供应商确定后，应实现相同的 `evaluate(result)` 接口，
并保存供应商、版本、原始响应和检测时间。

## 当前接口

| 方法 | 路径 | 登录要求 | 作用 |
| --- | --- | --- | --- |
| GET | `/api/auth/status` | 否 | 查询注册开关 |
| GET | `/api/auth/me` | 否 | 查询当前会话和画像版本 |
| POST | `/api/auth/register` | 注册开启时 | 建立账号和首版画像 |
| POST | `/api/auth/login`、`/api/auth/logout` | 否 | 登录或注销 |
| PUT | `/api/profile` | 是 | 保存新的画像版本 |
| GET | `/api/library/slices` | 否 | 查看领域切片统计 |
| GET | `/api/history`、`/api/study/status` | 是 | 查看个人历史或实验统计 |
| POST | `/api/run`、`/api/feedback` | 是 | 运行并保存单次结果 |
| POST | `/api/experiments/run` | 是 | 保存四组 Mock 对照 |
| POST | `/api/surveys` | 是 | 保存本轮问卷 |

## 初始化两组完整示例

```powershell
$env:PYTHONPATH="src"
python scripts/seed_local_database.py
```

脚本使用两组差异化合成画像生成完整的输入、Agent 轨迹、论文快照、命题裁决与
个性化资源。如果数据库已经有至少两次研究会话，脚本会跳过，避免部署时重复写入。
