# 证据来源与检索

## 1. 为什么不能只检索 arXiv

arXiv 适合计算机、数学、物理和部分电子工程预印本，但不能覆盖所有问题。
芯片开发、便携设备、协议和硬件设计通常更依赖：

- 芯片与器件数据手册；
- 厂商应用笔记和设计指南；
- 官方 SDK/API 文档与示例代码；
- 标准组织和政府机构发布的规范；
- 已正式出版但未提交 arXiv 的论文。

因此实时研究链路采用“开放论文索引 + 权威技术文档”的组合，而不是把任一
单一网站视为完整知识库。

## 2. 当前数据源

| 数据源 | 当前作用 | 鉴权 |
| --- | --- | --- |
| 官方资料目录 | ESP-IDF、ESP-ADF、ESP32 Audio Design Guidelines | 无 |
| OpenAlex | 跨学科论文发现、摘要、DOI、开放状态 | 必须配置独立的免费 Key |
| Crossref | DOI、出版方、题录和部分摘要 | 公共接口 |
| arXiv | 预印本标题与摘要 | 公共接口 |
| Semantic Scholar | 摘要、引用网络、开放 PDF | 配置 Key 后启用 |

环境变量：

```text
OPENALEX_API_KEY=<OpenAlex Key；未配置时跳过该来源>
SEMANTIC_SCHOLAR_API_KEY=<可选的 Semantic Scholar Key>
```

这些是系统检索服务的 Key，不是用户的模型 API Key。服务器部署时应放在权限为
`0600` 的 `/etc/yanhai-agent-demo.env`，不能写入仓库。

## 3. 统一证据记录

所有适配器最终生成统一的 `Paper`/证据对象：

```text
paper_id
title
authors
published / year
summary
source_url
source_type
publisher
authority_tier
license
retrieved_at
content_hash
external_ids
```

稳定 ID 优先采用 DOI、arXiv ID、OpenAlex ID或官方目录 ID。不同来源若拥有相同
DOI，会被合并并优先保留权威等级更高、摘要更完整的记录。

## 4. 容错与拒答

- 数据源并行执行，各自限制超时；
- 429、超时和部分 5xx 会进行一次短退避重试；
- JSON 元数据在进程内缓存 15 分钟；
- 单源失败只产生警告，不中止其他来源；
- 本地知识库只有通过主题相关性检查后才能降级；
- 没有相关来源时不调用提出者；
- 提出者没有生成有效来源命题时返回结构化“证据不足”，不抛出 502；
- 模型引用列表之外的 ID 仍由确定性代码删除。

## 5. 官方资料目录

当前目录位于：

```text
data/knowledge/official_sources.json
```

目录只保存人工整理的简短证据摘要和原始 URL，不复制受限制的全文。新增资料时应：

1. 只选发布方、标准组织或项目官方仓库；
2. 填写规范 URL、发布者、版本日期和资料类型；
3. 摘要使用自己的文字概括，不大段复制原文；
4. 标明许可或使用边界；
5. 为内容生成或更新哈希；
6. 添加能够命中该资料的检索测试；
7. 定期检查链接和版本是否过期。

## 6. 添加新数据源

在 `src/yanhai/sources.py` 中实现：

```python
class SourceAdapter:
    source_id: str

    def search(self, queries: list[str], limit: int = 6) -> list[Paper]:
        ...
```

适配器必须：

- 设置可识别的 User-Agent；
- 遵守官方 API、robots、速率和许可要求；
- 不把付费墙后的正文当作开放全文；
- 提供稳定 ID、规范 URL和来源类型；
- 对超时、429 和错误响应有明确行为；
- 不在日志或返回结果中泄露 API Key；
- 使用固定夹具测试解析逻辑，不能让普通单测依赖公网。

## 7. verified / candidate 分区

当前基础论文从项目 JSON 加载后进入 `verified` 区。联网检索或增量上传的来源先进入
进程内 `candidate` 区，不自动参与后续本地正式检索。候选资料必须提供人工或规则复核
说明，才能通过 `promote_candidate()` 或 `/api/knowledge-candidates/promote` 提升。

候选区当前仅用于验证数据协议，服务重启后不会保留；正式版需要数据库、操作者身份、
版本、哈希和可撤销审计记录。
