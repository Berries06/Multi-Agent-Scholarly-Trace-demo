# 赛题对齐与作品边界

## 1. 核心判断

原始构想强调科研文献图谱、技术溯源、争议捕获和蓝海发现，创新点明确，但若只做“科研检索”会偏离赛题的主评分链路。赛题要求的是面向垂直领域技能培训的：

> 学情画像构建 → 多智能体协同调度 → 个性化资源生成 → 交互反馈 → 动态决策更新

因此，本项目把垂直领域定义为“AI 与多智能体方向的科研创新能力训练”，把科研图谱作为专业知识库与证据底座。最终用户既可以是高校学习者，也可以是需要技术情报训练的企业研发人员。

## 3. 项目创新表达

建议正式表述为：

1. **证据约束的多智能体博弈**：不是让多个模型重复回答，而是将提出、反证和裁决拆成不同目标函数。
2. **图谱驱动的个性化科研训练**：知识图谱不只用于展示，还参与盲区定位、证据检索、路径规划和蓝海假设生成。
3. **可回放的决策轨迹**：每个资源片段可追溯到画像特征、候选命题、批判意见、裁决分数和来源文献。
4. **闭环难度控制**：学习反馈改变后续解释层级和挑战任务，而非只改变推荐排序。

正式申报前不要使用未经证据支持的“首创”“零幻觉”“完善原型”“已获自主知识产权”等绝对化表述。

## 4. 当前基础版与正式参赛版的区别

当前版本的职责是固定数据协议、Agent 边界、证据链、可视化交互和评测口径。它使用确定性规则，确保现场无 API 时仍能演示。

正式参赛版需要继续补齐：

- 领域专家标注的 50 组以上测试用例；
- 真实全文或结构化摘要的合法采集和授权说明；
- LLM + RAG 与规则基线的对比实验；
- 单 Agent、无批判者、无图谱等消融实验；
- 专家盲审得到的真实幻觉率、适配率和覆盖率；
- 软件著作权或专利的实际受理材料。
