# 研究问题定义（1页）

## 项目目标
“研海寻踪”聚焦于跨文献知识发现：在海量科研文献中自动抽取高置信度关联，识别学术争议，并发现潜在研究空白。

## 核心科学问题

### Q1 跨文献隐性关联抽取
- 输入：多篇文献的标题、摘要、关键词与段落文本。
- 输出：跨文献实体-关系-证据三元组（含置信度与来源引用）。
- 指标：Precision/Recall/F1（关系抽取）、Top-K 命中率（关联推荐）。
- 基线：关键词检索 + BM25；单 Agent 摘要式抽取。

### Q2 争议检测与方法论冲突定位
- 输入：同主题文献中的方法、假设、结论结构化信息。
- 输出：争议边（conflict）与争议类型（方法冲突/假设迁移失效/结论矛盾）。
- 指标：争议识别 F1、争议类型分类准确率。
- 基线：单模型文本蕴含判别；人工规则关键词冲突检测。

### Q3 蓝海研究方向发现
- 输入：时序知识图谱与争议网络。
- 输出：潜在空白方向（候选主题 + 依据路径 + 可信度）。
- 指标：专家评分（新颖性/可行性/价值）、命中后续文献趋势比例。
- 基线：共词聚类 + 热点主题演化分析。

## 评测集与标注规范
- 领域范围：MVP 聚焦生物医药。
- 规模目标：1000 篇文献（MVP 示例仓库提供样本数据与流程）。
- 标注对象：实体、关系、争议类型、证据片段、时间信息。
- 标注协议：双人标注 + 仲裁；记录一致性（Cohen’s Kappa）。

## 验证假设
1. 多 Agent 博弈在关系抽取与争议检测上优于单 Agent。
2. 带证据引用 + 裁判置信度机制可显著降低幻觉关联。
3. 图谱拓扑分析可产生可解释的蓝海方向候选。
