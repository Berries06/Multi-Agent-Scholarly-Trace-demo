# 本机 WSL 实验部署

## 当前约定

| 项目 | 值 |
| --- | --- |
| 发行版 | Ubuntu 24.04 |
| 服务用户 | `snowsong` |
| 代码根目录 | `/home/snowsong/apps/yanhai-trace/current` |
| 持久数据 | `/home/snowsong/.local/share/yanhai-trace` |
| SQLite | `.../yanhai.sqlite3` |
| 监听地址 | `127.0.0.1:8877` |
| systemd 单元 | `yanhai-wsl-local.service` |

服务只监听 WSL 回环地址，Windows 通过 WSL 的 localhost 转发访问
`http://127.0.0.1:8877/`。这不是公网部署。宿主机的 `8876` 已被旧版
Windows 验证服务占用，因此 WSL 版本固定使用 `8877`，避免覆盖或终止旧进程。

## 发布原则

代码使用版本目录和 `current` 软链接；数据库位于代码目录之外。升级时只切换
代码软链接，不删除或覆盖数据库。

systemd 模板位于：

```text
deploy/systemd/yanhai-wsl-local.service
```

服务环境变量：

```text
PYTHONPATH=/home/snowsong/apps/yanhai-trace/current/src
YANHAI_PROJECT_ROOT=/home/snowsong/apps/yanhai-trace/current
YANHAI_DATA_DIR=/home/snowsong/.local/share/yanhai-trace
```

当前源码还支持：

```text
YANHAI_REGISTRATION_OPEN=1
YANHAI_COOKIE_SECURE=0
YANHAI_COOKIE_PATH=/
```

注册默认关闭。本机组织验证时可临时开启，创建完测试账号后再次关闭并重启服务。
本机 HTTP 环境保持 `YANHAI_COOKIE_SECURE=0`；只有 HTTPS 公网环境才设为 `1`。

免费 DeepSeek 使用当前版本目录内的
`secret/DeepSeekAPI.txt`。发布归档不会携带 `secret/`，因此每个新版本启用前都要
由维护者以安全方式放置 Key，并将文件权限限制为服务用户可读。密钥在进程启动时
读取，新增或替换后必须重启服务。这个“密钥随版本目录放置”的方式只适合当前粗略
验证，云端正式方案应改为 systemd credentials 或专用密钥服务。

## 初始化与验收

部署后先生成两组竞赛输入输出示例：

```bash
cd /home/snowsong/apps/yanhai-trace/current
PYTHONPATH=src \
YANHAI_DATA_DIR=/home/snowsong/.local/share/yanhai-trace \
python3 scripts/seed_local_database.py
```

然后检查：

```bash
systemctl status yanhai-wsl-local.service --no-pager
curl --fail http://127.0.0.1:8877/api/health
curl --fail http://127.0.0.1:8877/api/library/slices
```

端到端验收还应创建测试账号、运行 A/B/C/Full 对照、提交问卷，并确认数据库中
存在 1 个共享证据快照、4 个回答版本、4 个检测结果和 1 份问卷。

注意：`8877` 上已运行的版本不会自动跟随 Windows 工作区变化。更新源码或前端后，
必须重新打包到新的版本目录、切换 `current` 并重启服务，才能声称新增功能已经部署。

## 数据备份

写入中的 SQLite 使用 WAL 模式，不能只复制主数据库文件。建议停止服务后备份：

```bash
sudo systemctl stop yanhai-wsl-local.service
cp -a /home/snowsong/.local/share/yanhai-trace \
  /home/snowsong/.local/share/yanhai-trace-backup-YYYYMMDD
sudo systemctl start yanhai-wsl-local.service
```

不要在没有确认路径的情况下递归删除 `apps` 或 `.local/share`。
