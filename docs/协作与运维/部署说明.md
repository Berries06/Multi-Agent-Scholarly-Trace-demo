# 产品部署说明

## 统一拓扑

生产环境只运行一个产品服务：FastAPI 在 `127.0.0.1:8766` 提供 `/api` 和构建后的 React 静态资源。Nginx 负责 HTTPS、子路径转发、限流和 SSE 禁用缓冲。


## 依赖

- Python 3.12；
- Node.js 20 或更高版本（只在构建前端时需要）；
- `secret/DeepSeekAPI.txt`（可选，仅免费 DeepSeek 模式需要）；
- 可写的 `outputs/`，用于 SQLite、运行历史、缓存和实验产物。

## 手工部署

Windows 本地统一使用仓库根目录 `.venv`：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/环境/创建统一环境.ps1
```

Linux 服务器同样只创建发布目录中的一个 `.venv`：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install .
cd frontend
npm ci
npm run build
cd ..
YANHAI_COOKIE_SECURE=1 .venv/bin/python -m uvicorn yanhai.api:app --host 127.0.0.1 --port 8766 --workers 2
```

管理员创建首个账号：

```bash
.venv/bin/python scripts/后台创建用户.py --email member@example.com --nickname 研究员甲
```

## Docker Compose

```bash
docker compose up --build -d
curl http://127.0.0.1:8766/api/ready
```

Compose 只向宿主回环地址发布端口，并将 `outputs/` 挂载为持久化目录、`secret/` 只读挂载。公网部署必须由 HTTPS 反向代理提供访问，并设置 `YANHAI_COOKIE_SECURE=1`。

## systemd 与 Nginx

- 服务定义：`deploy/systemd/yanhai-agent-demo.service`；
- 站点片段：`deploy/nginx/agentdemo.locations.conf`；
- API 与 SSE 上游：`127.0.0.1:8766`；
- PDF 最大请求体：6MB；应用内有效 PDF 上限为5MB；
- SSE 路径必须设置 `proxy_buffering off`，读取超时至少 240 秒。

服务单元固定调用 `/opt/yanhai-agent-demo/current/.venv/bin/python`，运行数据写入 `/var/lib/yanhai-agent-demo`。切换发布软链接前，必须先在新发布目录创建并安装该唯一环境，并创建数据目录：

```bash
install -d -o yanhai-agent -g yanhai-agent /var/lib/yanhai-agent-demo
cd /opt/yanhai-agent-demo/releases/<version>
python3.12 -m venv .venv
.venv/bin/python -m pip install .
```

若发布在 `/AgentDemo/start/`，React 会自动把 API 请求发到 `/AgentDemo/start/api/`。Vite 使用相对静态资源路径，避免子路径部署时资源失效。

## 安全基线

- 产品无注册接口，只有后台脚本可创建用户；
- 会话 Cookie 为 `HttpOnly`、`SameSite=Lax`，HTTPS 下启用 `Secure`；
- `secret/`、数据库和运行输出不得进入 Git 或发布包；
- BYOK 只用于本次请求，不得记录完整请求体；
- Nginx 应对登录、运行、在线检索和上传接口设置合理限流；
- 数据库与 `outputs/` 应纳入服务器备份和恢复演练。

## 健康检查

```bash
curl http://127.0.0.1:8766/api/health
curl http://127.0.0.1:8766/api/ready
```

`/api/health` 表示进程可响应，`/api/ready` 验证知识库、画像和数据库目录。科研运行接口在未登录时返回 `401 login_required`，这是预期行为。
