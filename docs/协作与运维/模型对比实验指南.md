# 真模型对比实验 Runbook（拿到 Key 后第一步）

> 目标：Key 一到，10 分钟内跑出第一份"模型 × 角色"对比报告，不再有犹豫。

## 0. 前置（一次性）

1. 注册并领取 Key（渠道见对话记录/十大差距方案：DeepSeek / 智谱 GLM / 通义 Qwen / Kimi，备选 SiliconFlow 聚合）；
2. 把 Key 写进**项目根目录 `.env`**（已被 gitignore，不会提交）：

```
DEEPSEEK_API_KEY=sk-xxxx
ZHIPU_API_KEY=xxxx
QWEN_API_KEY=sk-xxxx
KIMI_API_KEY=sk-xxxx
```

3. 安装后端依赖：`python -m pip install "fastapi>=0.115" "uvicorn[standard]>=0.30" "python-multipart>=0.0.9"`；
4. 可选（本地小模型对照组）：装 Ollama 后 `ollama pull qwen2.5:7b`。

## 1. 第一轮：24 条压力集快速初筛（快、便宜）

```powershell
$env:PYTHONPATH="src"
python scripts/run_decision_experiment.py --models "deepseek:deepseek-chat,zhipu:glm-4-flash,qwen:qwen-turbo,kimi:kimi-k2"
```

- 产物：`outputs/experiments/decision-matrix-<时间>/REPORT.md`；
- 看什么：每列"接收精确率 / Gold 召回 / 不支持接收率 / token / 成本"；
- 决策：留下前 2–3 名进第二轮。

## 2. 第二轮：140 条 L2 用例（更稳的区间）

```powershell
python scripts/run_decision_experiment.py --cases data/evaluation/generated-decision-cases-v1.json --models "第一名,第二名,第三名"
```

- 看什么：140 条上各组合是否在"无证据/错证据/绝对化/类型错配"四类负例上全部守住（不接受 = 对）；
- 预期：LLM 批判者在"绝对化/时态体"上的表现 vs 规则基线，是第一个真正有区分度的看点。

## 3. 异质组合（前三名两两配对）

同一命令会**自动生成** critic=A / judge=B 的异质组合（模型 ≤3 个时）。读 REPORT.md 的
`hetero_*` 行，找"精确率 ≥ 90% 前提下成本最低"的组合。

## 4. 收口标准

- 声明决策标准（精确率 ≥ 90% → 选最便宜）；
- 记录每组合的 token 成本（价格表 `config/实验/experiment_models.json` 先填官网价格）；
- 把结论写进 `docs/研发记录/` 一份"模型选型报告"（含 run 目录与 SHA-256 引用）。

## 5. 常见坑

- 缺 Key 的组合会被**跳过并注明**（不是静默回退，别把它当结果）；
- ECONNRESET（淘宝镜像抽风）→ 重跑一次；反复出现 → 换官方源；
- 成本失控 → 先用 `--max-cases 8` 冒烟，再跑全量；
- 结论口径：**合成压力集/L2 是初筛，最终结论等 L3 人工核验锚点**（`scripts/generate_l3_sample.py` 已出 28 条抽查表）。
