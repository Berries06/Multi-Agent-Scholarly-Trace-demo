> 先记三个日子：**9 月 5 日交作品**（打包发邮箱）、9 月 20 日初审、11 月终审。
> 四个人四条线，互相验收：A 出题判卷、B 升级裁判、C 上真模型、D 说书装修。

## 一、先看总表

| 成员 | 通俗名字 | 主要任务 | 目标一句话 |
|---|---|---|---|
| **A** | 出题人和判卷人 | 准备"标准答案"（金标）、写判题规则、管数据、说清三个硬指标怎么测 | 让系统有真人判过的考题可考 |
| **B** | 裁判组 | 给每条关系记"流水账"，证据变了自动重算；分数线从拍脑袋改成数据学的校准 | 裁判不再靠关键词瞎猜 |

**互相验收的规矩**：谁做实验，谁就不能自己当验收人。A 的活由 D 验收，B 的由 C 或 D，C 的由 B 或 D，D 的数字由 A 和 B 把关。

## 二、为什么是这四块活（大白话背景）

**A 为什么是命根子？**
现在系统用的 24/140 条压力集只是"练习题"，不是"考试题"。评委问"你幻觉率多少"，只有拿真人判过的题目去测，数字才算数。没有标准答案，B 和 C 做得再好也只是自娱自乐。

**B 为什么必须升级？**
现在裁判靠固定分数线（0.78/0.58）和关键词判断，像老师只数字数不读内容。要改成：每条结论都记清楚"谁说的、哪句话、什么条件下、后来有没有被推翻"。文献查新也告诉我们：光"多几个智能体辩论"不算创新，这套"记账 + 自动重算 + 校准"有没有真效果才是创新点。

**C 为什么是命门？**
现在演示用的是规则假模型。比赛要求至少 3 个智能体真分工，评委必问"你真调模型了吗"。390 条 L2 考题已经备好，只差 Key。

**D 为什么不能省？**
体验分 15 分 + 作品书 = 评委看不看得懂。现在作品书初稿还没写新口径，界面"比之前好但一般"，文献还得继续查，防止答辩被问倒。

## 三、每个人的活（详细版）

### A：出题人和判卷人

**你负责什么**
1. 和 B 一起定"七条判断规则"——哪句话算支持、哪篇算独立来源、什么时候算被推翻、哪些情况必须人工复核；
2. 组织两个人各自独立标注题目（先 28 条，再扩到 60–100 条），答案不一样的地方请第三人拍板；
3. 所有数据编号、存档、算哈希（改了能查出来）；
4. 写一页纸：三个硬指标（幻觉率 <5%、适配 ≥85%、覆盖率 ≥90%）到底怎么测、分子分母是什么、错了哪几条。

**你接下来做什么**
- 本周（8-22 ~ 8-24）：和 B 开会定七条规则（约 1 小时）→ 两名同学各花 2 小时盲标 28 条 → 不一致的题仲裁 → 打包成"标准答案 v1"；
- 下周（8-25 ~ 9-01）：题目扩到 60–100 条；写"三指标怎么测"说明；
- 9-05 之后：补数据说明书；9-20 前把正式考题（test）交给 C——注意**只考一次**。

**怎么做（五步）**
选论文（查许可）→ 写判题规则（带例子）→ 两人各自判 → 对答案（不许私下统一）→ 仲裁打包（编号 + 哈希）。

**你的红线**：练习数据不能冒充考试成绩；考试题不能提前给 B 和 C 看。

---

### B：裁判组

**你负责什么**
1. 给每条关系记"流水账"：候选 → 接受 / 待查 / 拒绝 / 被取代，全程留记录；证据新增、删除、反驳、取代时自动重算状态；
2. 把裁判的分数线从"拍脑袋定的 0.78/0.58"改成"在练习数据上学出来的校准器"；
3. 批评不再写一段话，而是填"问题类型"（比如：证据错位、条件不符、来源不独立）；
4. 给 D 提供统一的证据数据结构（界面要靠它展示）。

**你接下来做什么**
- 本周（8-22 ~ 8-24）：跑 R007——同一串证据事件重放三遍，结果必须一模一样；
- 8-25 周：跑 R009（固定分数线 vs 学出来的校准器，比谁准）；跑 R010/R011（把"问题类型""硬护栏"各去掉一次，看会不会崩）；
- 9 月初：跑 R008（关系状态变了，下游的时间线、Idea、资源有没有跟着变）；把结论整理成作品书第 4 章素材。

**怎么做（五步）**
先和 A 对规则 → 写代码 + 用手算例子锁死的单元测试 → 跑实验留六件套文件 → 交给别人验收 → 登记进实验记录本（MLflow）。

**你的红线**：不能看考题调参数；实验失败（比如校准器不如固定分数线）也要照实记录——"简单方法够用"本身就是结论。

### C：真枪实弹组

**你负责什么**
1. 催 Key（填进项目 `.env`，不进聊天框、不进源码）；
2. 把真模型实验的"成绩单"补齐——现在跑完没有验证收据，等于试卷没盖章，数字不能进正式比较；
3. 先 8 条冒烟，再跑 390 条全量"模型×角色"矩阵；
4. 算清"每少错一条要花多少钱"，画出"风险—成本"图；
5. 维护 MLflow（团队实验记录本）。

**你接下来做什么**
- **8-23 前（只有人能干的活）**：负责人把 4 家 Key 填进 `.env`；
- 本周（不用 Key 也能做）：把模型矩阵脚本补上验证收据和幂等同步（R001–R003）；
- Key 到之后：8 条冒烟（R017）→ 8-28 起跑 390 条初版矩阵（先两家）→ 输出成本风险初表；
- 9-05 后：全量 4 家矩阵 + 成本表；给 D 提供录视频用的"真模型片段"（必须来自已验收的实验）。

**怎么做（五步）**
先定预算和价格表 → 小样跑通再全量 → 同一批题、同一预算下比结果 → 画图 + 算误差范围 → 让别人复核数字。

**你的红线**：哪家没 Key 就写"跳过"，**绝不允许偷偷用规则模型冒充真模型**。

### D：说书人和装修队

**你负责什么**
1. 文献继续查：和 A 分头复核 20 篇文献来源，把 9 篇"最近做得像我们"的论文逐条写清"我们差在哪"；
2. 专利正式检索（SooPAT / CNIPA / Google Patents），补上之前只查了标题的窟窿；
3. 前端按顺序做：先"关系证据档案页"（一条关系的原文、支持/反驳、状态变化时间线都在这页）→ 再证据图谱 → 标注控制台 → 实验账本美化；
4. 录 ≤10 分钟演示视频：画像输入 → 多智能体调度可视化 → 资源生成，一条龙；
5. 作品书定稿：补新口径、补"待测→实测"表、删掉一切"首创/领先"字样。

**你接下来做什么**
- 本周（8-22 ~ 8-25）：20 篇文献复核 + 9 篇差异表；专利检索正式版；
- 8-26 ~ 9-02：作品书定稿（第 2、4、7、10 章）；前端"关系证据档案页"最小版；
- 9-02 ~ 9-04：录视频 → 9-04 对着提交清单逐项打勾 → **9-05 交**。

**怎么做（五步）**
先定"什么能说"（口径）→ 界面只读数据、不自己算数 → 每页用三问验收（30 秒找到原文依据？能解释状态为什么变？每个数字查得到出处？）→ 视频素材全部来自已验收实验 → 交稿前再跑一遍禁用词检查。

**你的红线**：不隐藏失败的实验结果；大百分比必须带出处和样本量。

## 六、纪律（大白话八条）

1. 先想清楚再跑代码：测什么、怎么算赢、输了怎么办；
2. 考试题只考一次，调参数只看练习题；
3. 每个实验留"六件套"文件才算数（配置、原始结果、表格、汇总、报告、验证章）；
4. 失败的实验不删，也不许只挑好看的报；
5. 没 Key 就写"跳过"，不许拿规则模型冒充；
6. 不许把练习数据当考试成绩；不许把"多加了几个智能体"当创新；
7. AI 写的东西先当"可疑"，每个数字必须查得到文件和哈希；
8. 对外禁用"首创 / 首次 / 领先"，统一口径："候选机制，谨慎推进"。
