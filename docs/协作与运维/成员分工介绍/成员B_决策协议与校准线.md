# 研海寻踪 · 成员 B 工作说明

## 这个项目在做什么

"研海寻踪"是我们参加挑战杯揭榜挂帅专项赛（XH-202630，发榜单位上海云之脑）的作品：面向科研文献的知识图谱系统。核心问题是：大模型会把"A 能治 B"这种结论直接写进图谱却不给出处，图谱里缺的不是"抽取"，而是"裁决与更新"——谁来判断一条关系可不可信，证据变了图该怎么办。我们的答案是一套叫 EASG 的机制：每条关系带原文证据、结构化批评、校准过的风险分数和一条不可改写的裁决流水账；证据新增、删除、被反驳、被新论文取代时，状态自动重算，历史可以重放。

文献查新给这套方案的评级是"谨慎推进的候选机制"（4.0/10）。对外口径：禁用"首创、首次、领先"，统一说"候选机制，谨慎推进"。

## 现在走到哪一步了

系统端到端能跑，128 项测试全过。规则版三智能体是真实逻辑，不是摆设。最小 EASG 内核已经做了第一个实验：12 条手算的反事实案例里，事件流方案全部判对，而"只存当前值"的传统做法只对 3 条——这证明"证据变了自动重算"这条路走得通。真模型（三家已选定）的裁决代码也写好了，等 C 接 Key。最近还拆掉了四处"装出来的效果"：前端假思考动画改成后端真实轨迹，假流式改成逐帧真流式，作品书数字改成从实验产物实时读取，实验通过章改成真实校验后签发。

## 你要做什么

一句话：**把裁决从"拍脑袋判断"改造成"有账本、可复算、可校准的协议"，并用实验证明每个零件都不可或缺。**

分四块做：

**第一块，先把裁决协议定稿。** 从 A 那里拿《判题规则》，把规则翻译成代码里的事件模型：每条关系的裁决记成一条不可改写的事件（谁提的、基于哪条证据、批评了什么、裁判给了什么分、为什么接受或拒绝）。已有一个最小内核 `src/yanhai/easg.py`，文档开头的说明就是政策原文，你要把它从玩具版升级到与 A 的规则逐条对应的生产版，并让 A 核对签字。同时把批评从"写一段话"改成"填结构化问题类型"——证据错位、条件不符、来源不独立这些都要是固定字段，裁判只看字段做判断，不再靠关键词在中文句子里猜。

**第二块，把"分数线"变成"校准器"。** 现在裁判用 0.78/0.58 两个拍脑袋定的阈值。你要在练习数据上学一个校准器（逻辑回归或等距回归就够了），把裁判打分换算成"真正正确的概率"，输出 ECE、Brier 和风险—覆盖率曲线。如果学出来的校准器并不比固定阈值强，就照实写"固定阈值够用"，这是结论不是丢人。

**第三块，做消融实验，证明每个零件都有用。** 逐个拆：去掉事件历史、去掉时间条件、去掉结构化问题类型、去掉校准器、去掉硬护栏、把大模型裁判换成小模型。每个变体跑一遍同一批题目，记录哪个零件拆掉后精确率掉多少。哪个零件拆了没影响，就删掉它——我们的主张是"这套组合有效"，不是"零件越多越好"。

**第四块，把下游打通。** 关系状态变了，时间线、研究想法、学习资源都要跟着变，而且能解释为什么变。做完之后，冻结一份"证据契约"：前端要展示的每条证据长什么样、字段叫什么、从哪里取，写成文档交给 D。

## 你和别人的衔接

- **从 A 拿**：《判题规则》和标准答案集的练习部分。没有规则你不动代码；规则和代码逐条核对表由你起草、A 签字。
- **交给 C**：结构化批评的字段定义、校准器和触发策略（哪些情况必须叫大模型来判、哪些可以用便宜模型）、以及一套指标清单。C 拿这些去跑真模型矩阵，跑完把每一组的原始结果和失败案例拿回来，由你解释失败切片、判断是代码问题还是模型问题。
- **交给 D**：证据契约 v1 和一批真实的失败案例。D 的前端按契约渲染证据档案页，D 的审计实验用你的失败案例当题目。

## 做到什么程度才算比赛级

评委必问三句话："你凭什么接受这条关系？""证据被删了你怎么更新？""比单个模型强在哪？"你的工作做完的标志是：每一条 accepted 关系都能当场点开它的完整裁决流水账；删一条证据能立刻看到状态重算；消融表能说明白每个零件的贡献。三个回答里有一个靠猜，就要重做。

## 几条要注意的

考试卷不能看，调参数只在练习数据上做；每次实验跑完留齐六件套文件并让 C 或 D 独立复核后才算数；实验失败了也照实登记，删失败的记录是红线。
