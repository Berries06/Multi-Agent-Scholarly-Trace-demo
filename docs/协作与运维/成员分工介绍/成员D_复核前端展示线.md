## 你的核心责任

你负责把“研究可信”变成评委看得懂、点得开、查得到的作品。你的验收标准只有三条：

1. 三十秒内找到一条关系的原文依据；
2. 能解释关系状态为什么变化；
3. 任意实验数字可以回到原始 run、样本量和验证收据。

你是 A/B/C 正式产物的流程与复现 reviewer，但不是所有领域事实的最终裁判。科学标签由 A 组织领域标注与仲裁；你检查盲化、许可记录、哈希、统计和报告是否一致。

统一对外口径仍为“候选机制，谨慎推进”（4.0/10），禁用“首创、首次、领先、零幻觉”。

## 第一件事：完成最近工作差分，不承担大规模搜集

你的文献任务聚焦已经识别出的最邻近工作，不再承担“再搜 100 篇”的规模任务。至少复核 SciGraph-LLM、Semantic Units、StatefulDiscovery、FOIS traceability、SCIMKG、SELENE、iMAD/DOWN、CARP、TLSQKT。

每篇固定记录：

```text
正式出版状态或预印本状态
原文页码/章节和摘录位置
对方已经完成什么
与 EASG 重叠什么
我们尚未证明什么
当前可以说的最小差分
是否要求收缩主张
复核人和日期
```

你的职责是限制过强表述，不是努力证明对方“没有做到”。若 closest work 已覆盖主张，立即通知全队并缩小贡献。

专利检索由你牵头记录流程，A 复核检索边界，最终知识产权结论由负责人/导师承担。

## 第二件事：审核 A 的数据流程

你不重判所有科学标签，只检查：

- 盲标表是否隐藏自动标签、错误类型、系统输出和他人答案；
- 是否包含论文来源、版本、证据原文、上下文和跨度；
- 两名标注者文件是否相互独立；
- 初标者和仲裁者是否发生角色冲突；
- train/dev/test 是否按论文隔离；
- 许可、版本、哈希、分歧和修订记录是否完整；
- 程序练习题是否被明确标为 synthetic proxy。

通过后签署的是“流程和产物完整”，不是“领域事实必然正确”。

## 第三件事：只做最小 Claim Dossier

9 月 5 日前的前端核心只有一页：关系证据档案页。页面严格消费 B 的证据契约，不自行发明字段或重算数字。

最小页面结构：

```text
顶部：关系文本、当前状态、数据性质、规则版本
左侧：论文原文与字符跨度高亮
中部：支持/反驳/相关不足/无关证据卡
右侧：typed issue、硬护栏、校准风险、入图理由
底部：add/delete/refute/supersede/retraction-risk/human-override 时间线
追溯入口：run、数据版本、哈希、验证收据
```

人工改判必须填写理由和操作者，产生新事件，不能直接改写旧状态。

三问验收不过，就不继续做复杂图谱、动画和装饰性页面。

## 第四件事：整合作品书和视频

作品书重点：

- 第 2 章：closest-work 差分和边界；
- 第 4 章：EASG 是本项目定义的可执行协议，贡献需要实验支持；
- 第 7 章：只写 A 的测量协议和经验证数字，带分子、分母、CI、数据性质和失败案例；
- 第 10 章：主动写清小样本、proxy、非首创组件和未完成实验。

视频中的真模型片段只能来自 C 提供、verification 通过的 run。没有真实 gold 的数字必须显示 `synthetic proxy` 或 `human pilot`，不能用画面效果掩盖证据等级。

## 第五件事：独立复核正式 run

A/B/C 的正式产物统一使用一张复核清单：

1. manifest、配置、原始结果、汇总、失败案例、报告、verification 是否齐全；
2. 从 raw 能否重新得到 aggregate；
3. 样本数、运行次数、coverage 和 accepted 数是否混淆；
4. 数据性质、模型、价格、prompt hash 和代码版本是否齐全；
5. 是否省略失败模型、负结果或不利切片；
6. 报告措辞是否超过证据强度。

你自己的前端真人审计由 B 复核，不能由 D 自己签发自己的结论。

**从 A 拿**：盲标包、数据卡、分歧记录、测量协议和经人工仲裁的数据。你检查流程，不替代领域标注者。

**从 B 拿**：证据契约 v0.1/v1.0、状态样例和失败案例。页面字段不一致时先修改契约或适配层，不在前端补造数据。

**给全队**：closest-work 边界表、复核结论、Claim Dossier、作品书、视频和提交清单。
