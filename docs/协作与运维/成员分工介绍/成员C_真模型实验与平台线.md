# 研海寻踪 · 成员 C 工作说明

## 这个项目在做什么

"研海寻踪"是我们参加挑战杯揭榜挂帅专项赛（XH-202630，发榜单位上海云之脑）的作品：面向科研文献的知识图谱系统，核心机制叫 EASG——三个智能体（提出者、批判者、裁判）裁决一条关系能不能入图，证据变了自动更新。评委对"三个智能体"这个说法一定会追问三句："你真调了模型吗？""比单个模型强在哪？""成本划不划算？"这三个问题的答案都在你这条线上。

对外口径：文献查新评级 4.0/10，统一说"候选机制，谨慎推进"，禁用"首创、领先"。

## 现在走到哪一步了

系统端到端能跑，128 项测试全过。真模型的代码全部就绪：三家供应商（DeepSeek、Kimi、智谱）的接口是真实实现，LLM 版批判者和裁判带硬护栏与规则回退，实验脚本保证"缺 Key 就显式跳过，绝不偷偷用规则冒充模型"。三家模型目录和价格已经定稿入档，Key 也已经买好，只差填进 `.env` 文件。实验记录平台 MLflow 配好了，390 道冻结测试题备好了，就等你跑出第一批真模型数字。

## 你要做什么

一句话：**把三家真模型接进来，跑出"模型×角色"对比矩阵和风险—成本曲线，给全队提供唯一的真模型证据。**

分三块做：

**第一块，把 Key 和实验环境接好。** 三家的 Key 填进项目根目录的 `.env` 文件（变量名是 DEEPSEEK_API_KEY、KIMI_API_KEY、ZHIPU_API_KEY），Key 不发群、不进仓库。然后建实验专用环境：`python -m venv .venv-lab`，再装 `.[tracking]` 依赖。价格表已经入档在 `config/experiment_models.json`，控制台调价时你去更新并记下新日期。

**第二块，先冒烟再全量。** 第一步只跑 8 道题验证三家能真调通——命令是 `.venv-lab\Scripts\python.exe scripts/run_decision_experiment.py --models "deepseek:deepseek-v4-flash,zhipu:glm-4-flash,kimi:kimi-k2.6" --max-cases 8`。冒烟通过的标准有三条：结果文件里申请的模型列表不为空、token 统计有数字、没有任何组合被静默跳过。之后按定稿的矩阵跑全量 390 道题：六个模型各自单独跑一遍（同质组），再做六组跨模型搭配——glm-4-flash 配 deepseek-v4-pro、kimi-k2.6 配 deepseek-v4-pro、deepseek-v4-flash 配 glm-5-turbo、glm-4-flash 配 kimi-k3、deepseek-v4-pro 配 glm-4-flash、kimi-k2.6 配 kimi-k3（每组前半是批判者、后半是裁判）。每组的产出物：精确率、错误接收率、每道题的成本、token 数、耗时，全部留成六件套文件。

**第三块，画曲线、做冻结。** 把所有组合画成"成本—精确率"散点图，先圈出精确率过 90% 的组合，再在其中挑成本最低的，这就是最终推荐配置；其余组合的结果也全量保留，不许只报好看的。每组跑完同步进 MLflow，打上负责人、数据性质、主张编号这些标签。

**另外一件持续的事**：文献周报管线已经落地（`scripts/weekly_literature_scan.py`），每周跑一次扫描新论文，Key 填好后加上 `--interpret` 让便宜模型自动生成四问解读，产出周报和候选卡片，供 A 复核。

## 你和别人的衔接

- **从 B 拿**：结构化批评字段、校准器、触发策略和指标清单。你跑矩阵时按 B 给的指标记录，跑完把每组原始结果和失败案例交回 B 分析。
- **从 A 拿**：标准答案集的练习部分（随便跑），以及封存的考试卷——**只在 9 月 20 日前后跑最终主结果时用一次**，用之前和 A 确认，用完在实验配置里登记使用记录。
- **交给 D**：录视频和写作品书要用的"真模型片段"和最终矩阵数字。你只交出带验证章的 run 目录路径，D 直接引用，不允许拿一次性调参秀充数。

## 做到什么程度才算比赛级

评委问"比单模型强在哪"，你要能当场打开 Pareto 图指给他看：同样的精确率下，哪组组合花的钱最少，数字背后是哪个 run 目录、哪次验证。评委问成本，你要能报出每一组实验真实花掉的 token 和钱。到不了这个程度，真模型实验等于没做。

## 几条要注意的

缺 Key 就记"跳过"，绝不允许拿规则模型冒充；成本数字只认入档的价格表；每组实验跑完交 D 独立复核，复核通过的数字才允许进作品书和视频。
