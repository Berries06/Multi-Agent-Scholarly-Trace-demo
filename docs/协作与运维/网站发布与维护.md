## 4. 当前发布结构

```text
/var/www/mysite/
  index.html                         个人主页
  AgentDemo/
    index.html                       AgentDemo 介绍页
    install/
      index.html                     Qt 下载页
      styles.css
      YanhaiTrace-Windows-x64-*.zip

/opt/yanhai-agent-demo/
  releases/<version>/                Web 后端版本
  current -> releases/<version>/     当前版本软链接

/etc/systemd/system/
  yanhai-agent-demo.service

/etc/nginx/
  conf.d/agentdemo-rate-limit.conf
  snippets/agentdemo.locations.conf
```

Python 服务只监听 `127.0.0.1:8765`，公网请求统一经过 Nginx HTTPS。

## 5. 标准更新流程

### Web 版

1. 运行全部自动化测试；
2. 运行 `scripts/build_web_release.ps1`；
3. 上传 TGZ 到新的 `/opt/yanhai-agent-demo/releases/<version>/`；
4. 检查属主和只读资源；
5. 切换 `current` 软链接；
6. 重启 `yanhai-agent-demo`；
7. 检查健康端点和 systemd 日志；
8. 异常时把软链接切回上一版本。

### Qt 版

1. 更新版本号和发行说明；
2. 运行 `scripts/build_qt_release.ps1`；
3. 在 Windows 10/11 x64 上执行冻结版启动测试；
4. 计算 ZIP 大小与 SHA-256；
5. 同步 ZIP 到下载目录；
6. 同步更新下载页中的文件名、大小和 SHA-256；
7. 保留上一版本，直到新版本由人工验收。

### 页面或 Nginx

1. 备份现有文件；
2. 仅修改 AgentDemo 所需位置；
3. Nginx 修改后必须先运行 `nginx -t`；
4. 使用 `systemctl reload nginx` 热加载，不直接中断主站；
5. 同时检查个人主页和 AgentDemo，防止路由覆盖。

精确命令和回滚步骤见仓库根目录的
[`deploy/README.md`](../../deploy/README.md)。

## 6. 安全边界

- 用户 API Key 只随单次 HTTPS 请求进入服务进程内存；
- 不使用 Cookie、`localStorage`、`sessionStorage`、日志或文件保存用户 Key；
- Nginx access log 不记录请求体；
- 当前 Web 版提供账号系统；公开注册由 `YANHAI_REGISTRATION_OPEN` 控制且默认关闭，
  开启前确认限流、隐私说明和数据备份；
- 服务器托管的免费 DeepSeek Key 位于运行版本的 `secret/DeepSeekAPI.txt`，
  只允许服务用户读取，发布包不得包含该文件；
- 公网设置 `YANHAI_COOKIE_SECURE=1`，并核对
  `YANHAI_COOKIE_PATH=/AgentDemo/start/` 与反向代理路径一致；
- 当前仍缺少邮箱验证、密码找回、管理员权限和用户自助删除，不能按正式生产系统宣传；
- 线上真实模型调用可能产生供应商费用，验收应使用低额度测试 Key。
