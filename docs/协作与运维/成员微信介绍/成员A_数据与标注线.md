# 成员 A · 数据与标注线介绍（微信发送版）

## 一、我们是谁、在做什么（研究背景）

我们在做**"研海寻踪"**：一个面向科研文献的知识图谱发现系统，参加第十九届"挑战杯"揭榜挂帅专项赛（赛题 XH-202630，发榜单位上海云之脑）。评分四块：完整性 30 / 创新性 25 / 体验 15 / 实用价值 30。**9 月 5 日交压缩包，9 月 20 日初审，11 月终审**。

**问题是怎么来的**：现在的大模型很会写，但经常一本正经说错话——尤其在专业领域，它敢把"A 能治 B"直接写进知识图谱，却不说这句话出自哪篇论文、什么条件、论文后来有没有被撤回。我们调研了 100+ 篇顶会论文后发现：**图谱里最缺的不是"抽取"，而是"裁决与更新"**——关系的可信度谁来判、证据变了图怎么办。于是我们把研究问题聚焦成一个词：**EASG（证据裁决状态图）**——给每条关系记一本"证据账本"，三个智能体（提出者/批判者/裁判）裁决入图，证据新增、删除、反驳、取代时自动重算状态。

**诚实口径（对外必须统一）**：文献查新给了我们 4.0/10 的谨慎推进评级——这套组合协议是"候选机制"，不是"首创"。对外禁用"首创/首次/领先"，统一说"候选机制，谨慎推进"。

## 二、目前做到哪了

1. 系统**能端到端跑通**：论文丢进去 → 抽取 → 三智能体裁决 → 证据图谱 → 个性化资源（导读/实操/测评），全部真实代码，119 项测试全过；
2. 真模型裁决代码已就绪但**还没接进主链路**（缺 4 家 API Key，这是 C 的事）；
3. 自建了 **390 条分层测试用例**（三个领域 140+120+130，内容指纹 sha256 冻结）和 24 条压力命题消融（三智能体精确率 84.6% vs 最强基线 61.1%）；
4. 最小 EASG 内核已完成首个实验（R006）：12 条手算反事实案例上，EASG 全对、静态基线只对 3 条——证明"证据变了自动重算"这条路走得通；
5. 界面、实验记录平台（MLflow）、作品书初稿都已成型；本周刚把四处"装出来的效果"（假动画、手抄数字、假流式、自签通过章）全部拆掉，改为真实数据。

**但有一个命门没解决**：我们所有的测试题都是程序自动造的"练习题"，**没有真人判过的"考试题"**。评委问"你的幻觉率多少"，现在只能回答"待测"。**这件事就是你的板块，也是全队最重要的事。**

## 四、每个方法是怎么来的（idea 来源）

- **为什么必须真人判题**：赛题白纸黑字——"测试用例不足 50 组或缺乏真实领域数据，扣 10–20 分"。我们用 390 条程序生成的用例解掉了"数量"这一半，但"真实"这一半只能靠人工判卷补上；而且程序生成的"正确答案"和我们被测的裁决规则是同一套逻辑，自己考自己不算数。
- **为什么是 28 条起步**：`outputs/l3-sample.csv` 是已经准备好的分层抽样（正例/各类负例各若干），两名同学各 2 小时能判完——先跑通"双人盲标→仲裁→一致性"的流程，再扩量，比一上来判 100 条更不容易烂尾。
- **为什么两人判、第三人仲裁**：单人判卷无法知道"错题是题难还是判卷人走神"；两人一致的部分可信，分歧部分单独仲裁，再用 kappa 系数量化"两个人有多一致"——这是评审认可的规范做法。
- **为什么 test 只能考一次**：如果拿考试题反复调参，分数就变成"背答案"了。调参只在练习题（dev）上做，考试题（test）封存到 9-20 一次性用。

## 五、怎么用项目、怎么做你的实验（手把手）

**第一步：装环境**（10 分钟）
1. 装 Python 3.11+（官网安装时勾选 Add to PATH）；
2. `git clone <仓库地址>`，进入项目目录。

**第二步：先跑一遍系统看看它长什么样**（5 分钟）
- 双击 `RUN_DEMO.bat` → 浏览器开 `http://127.0.0.1:8765`，点几个画像和问题，看"多智能体调度→证据图谱→资源生成"全流程；
- 想体验产品界面：`SETUP_WEB.bat`（首次装依赖）→ `RUN_WEB.bat` → `http://127.0.0.1:5173`。

**第三步：你的判卷实验流程**（核心，总共约半天）
1. 打开 `outputs/l3-sample.csv`（28 行，列含义见 `docs/协作与运维/人工任务指南.md`）；
2. 把文件复制两份发给两名判卷同学（**别互相看**）；判卷规则：每行在"核验结论"列填 accepted / rejected / needs_review，并写一句理由；
3. 收回来逐行对比：一致的行直接过，分歧的行列出清单交仲裁人拍板；
4. 算 kappa（我可以给你现成命令）；把最终版存成 `outputs/l3-sample-v1-annotated.csv`，算 SHA-256 冻结；
5. 需要扩大抽样：`python scripts/generate_l3_sample.py --positives N --per-negative M --seed 42`（参数含义见脚本顶部说明），生成新表后重复 2–4。

**第四步：交作业**：把 gold v1 和测量协议一页纸发到群里，通知 B（他的代码要对着你的规则写）和 C（他 9-20 用你的 test）。
