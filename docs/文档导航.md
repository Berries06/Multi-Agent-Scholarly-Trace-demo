## 当前可交付状态

截至 2026-07-27：

- 离线 Mock 闭环保留且可独立运行；
- Web 版要求账号登录；公开注册由 `YANHAI_REGISTRATION_OPEN` 控制，默认关闭；
- 登录用户可选择服务器托管的免费 DeepSeek，也可为 DeepSeek、GPT、Claude、Kimi 临时提供自己的 API Key；
- Qt 版提供四页桌面工作台、明暗主题与后台推理；它使用本地合成画像，不接入 Web 账号会话；
- Web 版适配 `snowsong.top/AgentDemo/start/` 子路径；
- Windows Qt x64 提供无安装器、无代码签名的验证 ZIP；
- 本地 SQLite 已保存账号、版本化画像、领域论文切片、冻结证据快照、消融回答与问卷；
- 已部署的 WSL 验证服务运行在 `http://127.0.0.1:8877/`，不影响宿主机旧版 `8876` 服务；源码新增功能只有重新发布后才会进入该服务；
- 线上介绍页、Web 服务和下载页由 `snowsong.top` 托管；
- 自动化测试覆盖供应商协议、证据过滤、Mock 回归和部署约束。

本轮已同步供应商集合和账号注册测试夹具：供应商断言包含 `free-deepseek`，
账号接口测试会在用例期间临时开启注册并在结束后恢复环境变量。
