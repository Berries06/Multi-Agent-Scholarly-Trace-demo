## 可复用的结构经验

第一份样例是第十九届“挑战杯”全国大学生课外学术科技作品竞赛“揭榜挂帅”专项赛成果汇报书，值得复用的不是具体内容，而是以下组织方式：

- 在目录后设置“作品评估标准索引表”，把完整性、性能、创新、实用性等评分维度映射到正文证据和页码。
- 从问题背景和研究目标进入相关技术，再依次展开创新、系统设计、技术实现、成果展示与应用前景。
- 把架构、模块、数据、训练和性能结果写成可检查的技术证据，不只放产品截图。

第二份样例是 2025 全国大学生信息安全竞赛作品报告，值得复用的做法包括：

- 作品概述、作品设计、作品实现、测试分析、创新分析、总结展望和参考文献形成闭环。
- 单列开发流程、训练数据、模型效果、端到端测试、竞品对比和使用说明。
- 样例明确采用 A4；除标题外正文为宋体小四、1.5 倍行距，并要求匿名评审材料不出现学校、院系和导师身份。该要求只作为内部排版基线，最终必须服从本届赛事正式模板。

最终申报书与学术论文的统一格式见 [`申报书与论文写作规范.md`](../../协作与运维/申报书与论文写作规范.md)。
