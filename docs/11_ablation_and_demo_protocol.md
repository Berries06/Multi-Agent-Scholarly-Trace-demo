# 三智能体对比、消融与 Demo 协议

版本：2026-07-30
目标：证明收益来自异质职责和证据约束，而不是角色数量、候选变化或页面动画。

## 1. 两条评测轨道

### Track A：同候选池决策评测（当前 Demo 已实现）

所有方法接收完全相同的 24 条固定压力命题，只改变决策机制。它回答：

> 在候选质量固定时，批判者和独立裁判能否减少错误关系入图？

数据：`data/evaluation/decision_benchmark.json`。13 条命题有证据支持、11 条不支持。相较于原 12 条机制样例，新增了低置信真阳性、有效证据 ID 的语义错配、元数据证据越权、类型/方向错误等固定噪声。没有随机翻转标签，也没有为了制造“好看数字”调低结果。

| 变体 | 决策机制 | 要验证的假设 |
|---|---|---|
| E0 普通规则程序 | 只按候选置信度阈值 | 普通程序会接收高置信错误 |
| E1 单次判定 | 置信度 + 证据 ID 存在 | 单次 Agent 无法识别证据语义和类型错误 |
| E2 同质三路投票 | 三个几乎相同阈值多数表决 | 增加同质角色不能消除共享盲点 |
| E3 提出—批判—裁判 | 反证检查后独立裁决 | 异质职责减少错误接收 |

当前结果：

| 变体 | 接收精确率 | Gold 召回 | UAR | 证据绑定护栏 |
|---|---:|---:|---:|---:|
| E0 | 0.500（11/22） | 0.846（11/13） | 1.000（11/11） | 0.818（18/22） |
| E1 | 0.611（11/18） | 0.846（11/13） | 0.636（7/11） | 1.000（18/18） |
| E2 | 0.611（11/18） | 0.846（11/13） | 0.636（7/11） | 1.000（18/18） |
| E3 | 0.846（11/13） | 0.846（11/13） | 0.182（2/11） | 1.000（13/13） |

E3 的接收精确率与 Gold 召回 Wilson 95% 区间均为 `[0.578, 0.957]`，UAR 区间为 `[0.051, 0.477]`。它仍错误接收 B019、B020 两条“有效 ID 但语义错配”命题，并把 B013、B014 两条低置信真命题放入复核，故不是满分。这些数值只属于规则开发可见的压力集，不能表述为真实科学信息抽取性能。

### Track B：端到端抽取评测（提交论文前必须完成）

所有系统读取同一冻结 PDF 测试集，从实体/关系候选生成到最终入图全链路评测。建议：

- B0：词典 + 触发模式；
- B1：GLiNER + GLiREL；
- B2：SciBERT/DyGIE++；
- B3：DeepKE/OneKE；
- B4：Qwen2.5 单次结构化抽取；
- B5：最佳候选器 + 三智能体裁决。

Track B 不得使用测试集调阈值、提示词或 schema。

## 2. 正式消融矩阵

| 消融 | 固定项 | 删除/替换项 | 观察指标 |
|---|---|---|---|
| 去批判者 | 候选、裁判、阈值 | 批判输出为空 | precision、UAR、recall |
| 去独立裁判 | 候选、批判 | 提出者按自信直接决策 | 校准、错误接收 |
| 同模型三角色 | 候选与 token 预算 | 三角色共享模型/提示结构 | 与异构方案比较共享盲点 |
| 打乱证据 | 候选不变 | evidence 随机换论文 | 证据依赖性、shuffled-evidence accuracy |
| 去 schema | 文本与模型不变 | 类型约束关闭 | 类型错误率、relation F1 |
| 去图谱 | 同一论文集与生成器 | Idea 只读文本检索 | Idea 有用率、可追溯率 |
| 选择性辩论 | 模型不变 | 只在分歧/高风险边启动 | precision、时延、token 成本 |

## 3. 指标定义

```text
Accepted Triple Precision
= accepted 中关系正确且证据充分的数量 / accepted 总数

Unsupported Acceptance Rate (UAR)
= 被错误接收的不支持命题 / 金标准不支持命题总数

Gold Retention Recall
= 被接收的金标准支持命题 / 金标准支持命题总数

Evidence Binding Completeness
= accepted 中绑定至少一个有效 evidence_id 的数量 / accepted 总数
（结构护栏，不检查引用语义是否支持命题，不是精确率或覆盖率性能）

Evidence Span F1
= 预测证据字符跨度与金标准跨度的 micro-F1

Verified Triple Yield (VTY)
= 关系正确且证据充分的 accepted 三元组数 / 论文数
```

正式实验同时报告：实体 strict/relaxed F1、关系 micro/macro F1、ECE、Brier score、平均/95 分位时延、token/显存与人工复核负担。

## 4. 现场必须展示的三个案例

1. **完整方法成功**：有正确跨度且类型兼容的关系被接收，并能跳回论文和章节。
2. **基线失败、三智能体修正**：高置信但无证据/绝对化/方向错误命题被 E0/E1 接收，被 E3 拒绝。
3. **完整方法仍失败或保守**：普通共现进入 `needs_review`，或图谱 Idea 被标记 `novelty_status=unverified`，说明系统不会假装全知。

## 5. Demo 讲解顺序（约 7 分钟）

1. 选择本科生或企业分析师画像，说明输入差异；
2. 启动运行，先展示核心领域的 30 篇检索记录，以及其中 8 篇证据卡形成的论文—证据—实体链；
3. 依次解释提出者、批判者、裁判的输入输出；
4. 打开压力测试命题，展示原文缺失和裁判分数分解；
5. 展示四组同候选池对比，强调同质投票没有自动增益；
6. 查看 2018–2025 技术脉络；
7. 查看缺失边 Idea，强调“新颖性未验证”；
8. 切换第二个画像，展示资源内容和难度变化；
9. 可选点击 OpenAlex 扩展候选，解释联网结果为什么不能直接入图。

## 6. 威胁与报告边界

- 24 条命题仍然很小，且规则开发者知道错误类型，存在设计过拟合；
- 当前默认图谱使用人工转述的证据卡保证现场稳定，真实 PDF 批处理结果需独立评测；
- 当前候选器为词典/触发规则，不能代表 GLiNER、GLiREL 或 OneKE；
- 当前已报告二项 Wilson 95% 区间，但没有盲测、标注者一致性和重复运行，因此不写“显著提升”；
- 多智能体在共享模型、共享证据或任务简单时可能不优于单智能体。

正式 Track B 至少冻结 60 条候选关系（建议 6 篇开发阶段未见论文、每领域 2 篇），由两名标注者独立判断关系、方向与证据跨度，冲突经第三人仲裁。压力集只负责回归，不替代盲测。
