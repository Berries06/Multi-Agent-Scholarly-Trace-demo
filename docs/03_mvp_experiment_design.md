# MVP 与可复现实验设计

## MVP 范围
- 单学科：生物医药。
- 文献规模：目标 1000 篇（仓库内提供小规模样本用于流程验证）。
- 流程阶段：
  1) 单轮抽取
  2) 多轮（当前最小为一轮）博弈裁决
  3) 图谱构建与导出

## 消融实验
- A1：仅提出者（无批判者、无裁判者）
- A2：提出者 + 裁判（无批判者）
- A3：完整三 Agent

## 对比基线
- B1：关键词检索 + 模板抽取
- B2：单 Agent 摘要推断

## 输出产物
- claims.json：命题与证据
- graph.json：图谱节点与边
- evaluation.json：指标与误差分析
