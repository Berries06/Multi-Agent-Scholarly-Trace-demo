## 6. 给队友的通俗介绍（可直接转发）

**我们在做什么。** 现在的大模型很会写东西，但经常一本正经地说错话——尤其在专业领域，它敢把"A 能治疗 B"这种话直接写进知识图谱，还不告诉你这句话是哪篇论文说的、那句话还在不在有效期内。我们要做的，就是给"AI 判断论文里哪句话可信"这件事装一套**账本**：每条结论都记清楚"是谁说的、原文哪一句、什么条件下成立、后来有没有被新证据推翻"；证据变了，账本自动重算，而不是把过时结论一直留在图谱里。

**现在做到哪了。** 骨架已经立住：能跑起来的完整流程（丢一篇论文进去，它抽取关系、三个"AI 角色"互相挑毛病、给出接不接受的结论、还能生成导读和练习题），有网页界面和实验记录平台，准备了 390 道测试题，代码通过了 119 项测试，数据的诚实标注纪律也不错——我们自己造的数据都老老实实写着"这是练习数据，不是真实成绩"。

**还缺什么。** 三件大事：第一，**真正的模型裁决还没接上**——现在跑的是我们自己写的规则版"AI 角色"，不是花钱调用的各家大模型（代码写好了，只差 API 钥匙没填）；第二，**还没有真人判过的考题**——评委问"你的准确率多少"，我们现在只能回答"还在测"，因为判卷的人（两个同学每人两小时）还没到位；第三，**界面和作品书里有几处"装出来的效果"要拆掉**——比如网页上那个"AI 思考过程"动画其实是写死的文案，作品书里的数字是手工抄进去的、不是从实验里读出来的。这些不拆，答辩被问到就是硬伤。

**重点突破什么。** 按顺序：先拆掉所有"装出来的效果"（假动画、抄进去的数字），把话改成实打实的；然后催钥匙、接真模型，跑出"哪个模型组合又好又便宜"的对比；同时把 28 道题让人判出来，拿到第一批真实数字。这三步做完，9 月 5 日交上去的就是一个"说的和做的完全一致"的作品。
