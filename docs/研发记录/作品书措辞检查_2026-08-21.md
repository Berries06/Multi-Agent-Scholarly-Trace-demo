## 3. 复查方法（供定稿人直接使用）

```powershell
# 从 docx 抽全文后 grep 禁用词
python -c "import zipfile,glob,re;f=glob.glob('docs/申报材料/*.docx')[0];xml=zipfile.ZipFile(f).read('word/document.xml').decode('utf-8','ignore');xml=re.sub(r'</w:p>|</w:tc>',chr(10),xml);xml=re.sub(r'<w:t[^>]*>(.*?)</w:t>',lambda m:m.group(1),xml);t=re.sub(r'<[^>]+>','',xml);open('tmp/workbook_text.txt','w',encoding='utf-8').write(t)"
# 然后 grep 首创|首次|领先|突破|世界第一|显著优于|远超|零幻觉
```

> 本次检查的临时提取文本不提交仓库（`tmp/workbook_docx_text.txt` 用完即删）。
