# 创新点与获奖突破方向（2026-08-20 自主分析）

> 目标：回答三个问题——我们真正创新的地方是什么？哪些是普通工程不能冒充创新？
> 围绕赛题评分（完整 30 / 创新 25 / 体验 15 / 实用 30），哪些突破性价比最高？

## 一、创新点盘点（诚实分级）

### A 级：真正的差异化创新（作品书要重点讲）

**A1. 证据优先可追溯图谱（Evidence-first KG）**
`paper → CONTAINS → evidence → MENTIONS → entity → relation`，每条关系强制携带
`evidence_ids` + 章节 + 字符跨度。**任何一句生成内容都能点回论文原句**。
这不是 prompt 技巧，是数据结构层面的"高保真知识溯源"——赛题"幻觉防控与知识
溯源方案完善"的直接命中。多数参赛作品只做"RAG 检索 + LLM 生成"，没有这个
证据结构。

**A2. 模型无关的最终护栏（Model-independent Hard Guard）**
无论批判者/裁判用规则、小模型还是大模型，"无有效证据 / 绝对化谓词 → 强制
拒绝"这最后一道闸是独立于模型存在的。**防幻觉不依赖模型自觉**——这是对
"多智能体交叉验证"的工程强化，也是可演示、可测试的。

**A3. 语义力度校验（时态/体/情态，Factivity Check）**
批判者六查里包含"进行中/尝试过 ≠ 已完成"（未完成体悖论，ACL 2026《The
Imperfective Paradox in Large Language Models》为理论锚点）。把语言学里的
语义蕴涵检查变成可执行规则，这是**有文献根基的细节创新**，绝大多数作品没有。

**A4. 可复现的科研实验纪律本身成为系统特性**
冻结压力集、成员出题+硬断言的实验台、Wilson 95% 区间、无静默降级、SHA-256
复现回执——把"AI 辅助科研的可信性"做成可审计流程。评委看作品书附录时，
这套纪律是"科学定标"四个字的实证。

### B 级：好的工程集成（可讲，不可吹成创新）

- 三智能体异质分工（提出/批判/裁判）——借鉴 CAMEL/MetaGPT 思路；
- 意图驱动图检索（breadth/depth/hybrid）——GraphRAG 启发；
- 图谱驱动动态出题（从 accepted 三元组生成测评）——工程上干净，方法上常规；
- 分层决策成本阶梯（规则→小模型→大模型）——对齐"极低成本"的工程方案。

### C 级：诚实声明不能写的

- "多智能体辩论"本身不是我们首创；
- 个性化（按难度档位生成资源）是赛题的通用要求，不是我们的创新；
- GraphRAG/GLiNER 等是外部工具，只能写"采用"，不能写"提出"。

## 二、围绕获奖的六个突破（按性价比排序）

### 突破 1（命门）：真实模型三智能体 + 消融自证
- 做什么：差距 1（LLM 批判者/裁判/提出者，异质组合对比）。
- 为什么值：创新 25 分的全部论述（交叉验证/辩论消除幻觉）都挂在"真的调了模型"上；
  且消融报告直接回答评委必问的"怎么证明机制有效"。
- 演示用法：视频高潮放"去掉批判者 → 幻觉率上升"的对比镜头。
- 状态：代码就绪（llm_decision.py + 实验框架），等 Key。

### 突破 2：把"语义力度校验"做成可演示功能
- 做什么：输入一句话（如"作者正在研究 X"）→ 系统自动标注"进行中≠已完成，
  不能推出 X 成功"→ 作为批判者显式维度进裁决理由。
- 为什么值：有 ACL 2026 理论锚点的差异化创新，评委印象深、好提问、好写进论文。
- 状态：规则版已在批判者六查中；可加独立演示面板。

### 突破 3：证据链溯源可视化闭环
- 做什么：前端力导向图谱（已完成）+ 资源页每个论断可点击回 evidence 原文跨度。
- 为什么值：体验 15 分的核心镜头，"高保真知识溯源"从口号变成看得见的东西。
- 状态：图谱已上线；资源论断跳转证据是下一步。

### 突破 4：真实数据锚点（L3 人工核验）
- 做什么：团队抽查核验 L2 自动标签 20–30 条 + 计算一致率（Cohen's κ）。
- 为什么值：实用 30 分的"科学定标"、三个硬指标的真实锚点；也是"缺乏真实
  领域数据"扣分点的防御。
- 状态：L2 已生成 140 条；等团队做 L3（约 2–3 小时人工）。

### 突破 5：成本账本
- 做什么：每个 Agent 记 token/耗时/成本，前端展示"本次生成 ¥0.023 / 3200 token"；
  多模型价目表折算。
- 为什么值：赛题反复强调"极低成本"，有账本就是有说服力。
- 状态：UsageAccumulator 已就绪；前端展示待做。

### 突破 6：答题反馈闭环（赛题要求③深挖）
- 做什么：学习者答错 → 智能体决策"降维解释"；答对 → "进阶挑战"；用知识
  追踪状态（我们知识库里有 DKT/知识追踪论文）动态调难度。
- 为什么值：赛题明写的"动态迭代机制"，多数作品只做静态资源。
- 状态：目前只有 too_hard/too_easy 难度档；可加深为题目级自适应。

## 三、10 分钟演示视频的叙事建议（先记下）

```
00:00-01:00 问题引入：学习者打开系统，输入问题（企业分析师学 GNN 材料发现）
01:00-03:00 多智能体调度可视化：5 个 Agent 依次点亮，边上是各自的输入输出
03:00-04:30 证据链：生成资源里的论断 → 点击 → 论文原句（字符跨度高亮）

06:00-07:30 消融高潮：去掉批判者 → 幻觉率上升（数据表 + 置信区间）

```

## 四、一句话战略判断

**我们的牌不是"多智能体"（人人都有），而是"证据结构 + 模型无关护栏 +
语义力度校验 + 可复现纪律"这四个能写进论文、能演示、能被验证的具体机制。**
作品书和视频的每一章，都应把篇幅给这四个点，而不是堆角色数量。
