## 2. 系统研究方向与内容

- **定位**：把"科研论文 → 证据图谱 → 多智能体裁决 → 个性化学习资源"做成**证据可追溯**的闭环，解决"大模型生成专业内容有幻觉、不可控"的赛题痛点；
- **数据流**：论文正文/证据卡 → 结构解析 → 实体/关系/证据跨度抽取 → 提出者→批判者→裁判 三智能体裁决 → accepted 关系入图 → 技术演化脉络 / 缺失边 Idea / 个性化资源（导读+实操+测评）；
- **5 角色**：2 前置（论文知识抽取 Agent、用户意图感知 Agent）+ 3 决策（提出者、批判者、裁判）；
- **四大真创新**（作品书重点，见 `docs/研发记录/创新点与获奖突破方向.md`）：
  1. **证据优先图谱**：paper→CONTAINS→evidence→MENTIONS→entity→relation，每条关系强制带 evidence_ids+章节+字符跨度，任何生成内容可回原文句子；
  2. **模型无关硬护栏**（hard_guard）：无有效证据/绝对化谓词 → 强制 rejected，任何模型绕不过；
  3. **语义力度校验**：时态/体检查（进行中/尝试≠已完成，未完成体悖论），理论锚点 ACL 2026《The Imperfective Paradox in Large Language Models》；
  4. **可复现科研纪律**：冻结压力集、成员出题实验台、Wilson 95% 区间、cases_sha256 内容指纹、无静默降级；
- **B 级工程集成**（可讲不可吹）：异质三智能体分工、意图驱动图检索（breadth/depth/hybrid）、图谱驱动动态出题、规则→小模型→大模型成本阶梯；
- **C 级诚实声明**：多智能体辩论本身、GraphRAG、个性化都不是我们首创，只写"采用/借鉴"。
