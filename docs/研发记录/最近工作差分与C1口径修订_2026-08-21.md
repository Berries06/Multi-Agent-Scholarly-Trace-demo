## 2. 差分表

### 2.1 P101 StatefulDiscovery（arXiv 2606.11851v1）

- **重叠面**：外部化调查状态把证据与声明强度耦合；support / weaken / refute / inconclusive 的局部裁决；置信校准；状态驱动后续探索决策。
- **本系统独有（EASG）**：文献**字符级证据跨度**作为一等证据；**入图准入状态**（accepted / needs_review / rejected / superseded）；**证据事件**（add/delete/refute/supersede）触发当前投影重算与**重放**；**human override** 事件；异质 proposer–critic–judge + 模型无关 hard guard。
- **对方独有**：L1 frontier 预算控制；可执行查询（代码运行输出）作为证据；40 个真实数据发现任务 + ES/DV 裁判分 + 人工验证。
- **对 C1 的裁决**：触发缺口矩阵第 8 节的"**缩小**"动作（其"状态语义 + 证据校准声明"与 C1 表述重合），**不触发撤回**（无字符级证据事件、无入图评测协议）。
- **行动**：作品书 related work 必须引用并列出上表差分；"evidence-calibrated" 自我措辞避让，改称"evidence-bound adjudication（证据约束裁决）"。

### 2.2 P102 Reliable Post-Retrieval Assembly（arXiv 2606.01435v2）

- **重叠面**：冲突消解不能交给 LLM 自由文本判断；确定性策略执行；证据抽取与策略执行分离；决策可日志化、可审计、可替换。
- **本系统独有（EASG）**：证据充分性裁决（不只是"哪个版本更新"）；语义力度/typed critique；校准风险；human override；入图准入语义。
- **对方独有（实测数字，v2）**：MAB FactConsolidation 上 LLM 调解冲突在规则明示时仍大幅失败（最强系统单跳 54%、多跳全部 ≤7%）；结构化装配全管道 +10.8pp（262K +21pp）；**但策略执行器隔离仅 +2.0pp 平均、262K 0pp**；LongMemEval 无效（26/45 vs 29/45，McNemar p=0.45）。
- **对 C1 的裁决**：不构成竞争，**作为支撑引文采用**：
  1. 支撑 hard_guard / 确定性 supersede 组件——"模型无关的显式策略执行"有直接实证；
  2. 它的消融教训直接指导 Block 3：**必须把"接口分离"与"确定性执行"拆开测**，否则会高估 hard_guard 的贡献（对方自己的结论是收益主要来自接口分离）；
  3. 对方诚实汇报的 confound（全管道比较、温度不同、抽取重跑）正是我们 B3/B4 设计里已禁止的做法，引用它等于给我们的实验纪律背书。
- **行动**：作品书与实验计划引用；Block 3 消融表增加一行"policy executor：LLM vs 确定性"对照。

## 3. C1 措辞修订（供作品书直接引用）

- **旧表述（撞 P101，弃用）**：把"状态化证据校准声明（stateful evidence-calibrated claims）"本身当新颖性。
- **新表述（建议）**：C1 的创新不是"证据校准的状态机"本身（StatefulDiscovery 已有相邻工作），而是**面向文献关系入图**的证据裁决协议：每条候选关系必须携带字符级证据跨度，经支持/反驳、条件/时态的结构化批评与校准风险裁决后获得准入状态；证据新增、删除、反驳、取代作为**不可变事件**触发状态重算与重放；人工覆核是同一协议内的一等事件。
- **禁用表述**：首创 / 首次 / 领先 / "我们提出 EASG"。
- **口径**：EASG 是指导书定义的概念，本项目贡献是可执行协议与实验证据。
