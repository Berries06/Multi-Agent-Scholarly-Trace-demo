# 决策层语义漏洞：已知缺陷与研究线索

> 状态：研究线索记录（2026-08-19）。本文件只沉淀"观察到的问题"与"待探索方向"，
> 不改变当前代码行为；核心决策层重构时再回到这里逐项处理。

## 一、为什么单独记这份笔记

AI 生成的裁决代码在中文领域论文上会暴露"语义漏洞"——不是语法错，而是
模型/规则对自然语言的深层语义（时态、体、情态、别名、hedging）理解偏了，
导致误拒或幻觉。这类问题无法靠一次性 review 找全，需要：

1. 用实验台持续喂真实论文暴露案例；
2. 把每个漏洞沉淀成"可回归的压力命题"；
3. 探索用小模型/专用验证器做便宜的语义校验。

## 二、本次实验台已发现的缺陷（先放着，未修）

- **位置**：`src/yanhai/agents.py` → `CriticAgent.critique` 的"证据跨度覆盖"检查。
- **现象**：用英文规范名去字面匹配证据原文。中文论文里被中文别名匹配到的实体，
  其规范名是英文，导致"跨度未同时覆盖两端"被误判，语义正确的关系被大量误拒。
  （`pipeline_lab.py` 跑中文示例论文，8 条命题只 accepted 1 条。）
- **正确/错误对照**：
  - `GLiNER -uses-> GLiREL`：规范名就是英文，字面命中 → accepted（对）。
  - `multi-agent debate -improves-> hallucination control`：证据是中文
    "多智能体辩论机制…幻觉"，规范名是英文 → **误拒**（错）。
- **修复方向**：跨度检查应比对实体的表面形式（`mentions.surface_form`）与
  别名（`aliases`），而不是只比对 `canonical_name`。
- **验证**：修复后应新增一条中文论文压力用例，防止回归。

## 三、外部研究线索：时态/体导致的语义漏洞（已找到权威来源）

- **现象**：模型看到过去进行时/未完成体动词（如 "I was working on X" /
  "attempted to do X"），直接推断"这件事成功了"，进而生成幻觉内容。
  但自然语言里"过去在做某事 / 尝试做某事" **不等于** "做成了某事"。
- **术语**：这在语言学里叫 **imperfective paradox（未完成体悖论）**——
  "was building a house"（进行体）并不蕴涵 "built a house"（完成体）。
- **权威论文（2026 ACL 长文）**：
  *The Imperfective Paradox in Large Language Models*，
  <https://aclanthology.org/2026.acl-long.689/>（arXiv:2601.09373）。
  论文直接检验 LLM 在未完成体/完成体蕴涵上的系统性问题——正是团队伙伴
  视频里描述的那类"时态误判 → 幻觉内容"。
- **本质**：模型把"时态/体"（temporal/aspect）当成了"事实完成态"
  （factive），混淆了 `attempted / was doing / did / achieved` 的蕴涵边界。
- **小模型校验方向（低成本批判子 Agent 的旁证）**：
  *Verify Before You Commit: Towards Faithful Reasoning in LLM Agents via
  Self-Auditing*（用 Qwen 2.5-7B 做自查校验），说明 7B 级小模型可承担
  语义校验/事实归属把关，代价远低于大模型。
- **对我们的意义**（留到核心决策讨论）：
  1. 批判者/裁判的"科学主张验证"应把时态/体/情态/hedging 检查纳入；
  2. 可以用小模型做"语义蕴涵"专用校验器，而非让一个大模型自提自审；
  3. 代价极低，适合作为多智能体里的低成本批判子 Agent；
  4. 可直接以《Imperfective Paradox》为基准构造压力命题集（见第五节）。
