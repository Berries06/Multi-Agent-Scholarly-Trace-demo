# 实验设计与消融协议

本文描述当前仓库唯一受支持的实验口径。产品运行时只有提出者、批判者、裁判三个核心决策 Agent；论文知识抽取和意图感知是前置专职 Agent，画像、图检索和资源生成属于服务层。

## 1. 评测目标

实验用于检验收益是否来自异质职责和证据约束，而不是角色数量、候选池变化或界面动画。当前结果属于可重复的开发阶段代理评测，不能替代真实论文盲测和真实用户研究。

## 2. Track A：固定候选池决策评测

数据源为 `data/evaluation/decision_benchmark.json`。四个变体接收相同的 24 条冻结候选命题，只改变决策机制：

| 变体 | 当前机制 | 主要比较问题 |
|---|---|---|
| `rule_program` | 仅按候选置信度阈值 | 普通阈值是否接收高置信错误 |
| `single_pass` | 置信度与证据 ID 存在性 | 单次判定能否识别语义、类型和方向错误 |
| `homogeneous_vote` | 三个同质阈值多数表决 | 增加同质角色能否消除共享盲点 |
| `evidence_triad` | 提出—批判—裁判 | 异质职责是否减少错误接收 |

当前冻结结果由 `src/yanhai/ablation.py` 实时计算：

| 变体 | 接收精确率 | Gold 召回 | UAR |
|---|---:|---:|---:|
| `rule_program` | 50.0% | 84.6% | 100.0% |
| `single_pass` | 61.1% | 84.6% | 63.6% |
| `homogeneous_vote` | 61.1% | 84.6% | 63.6% |
| `evidence_triad` | 84.6% | 84.6% | 18.2% |

压力集对规则开发者可见，样本量小；这些数值不得表述为公开科学信息抽取基准成绩。

## 3. 六组回归实验

| 目录 | 当前评估类型 | 回答的问题 |
|---|---|---|
| `01_core_ablation` | `synthetic_proxy` | 四种 Track A 机制在同一候选池上的差异 |
| `02_provenance_falsification` | `synthetic_proxy` | 证据缺失、元数据越权、语义错配、过度声明和方向错误如何影响裁决 |
| `03_dynamic_knowledge` | `self_supervised_proxy` | 三种反馈下目标难度、适配指标和三智能体轨迹是否稳定 |
| `04_query_robustness` | `synthetic_proxy` | 主题变化和绝对化诱导是否仍受证据约束 |
| `05_workload_scaling` | `simulation_only` | 重复扫描行增加时的墙钟耗时、P95 和输出格式是否稳定 |
| `06_end_to_end_regression` | `simulation_only` | 9 个合成案例是否完整通过当前协议 |

每次运行写入独立时间目录，至少生成 `run_config.json`、`raw_results.json`、`cases.csv`、`summary.json` 和 `REPORT.md`。协议定义位于 `tests/experiments/`，产品实验账本通过 `/api/experiments` 读取已索引结果。

## 4. 复现命令

```powershell
.venv\Scripts\python.exe -m tests.experiments.run_all
.venv\Scripts\python.exe -m tests.experiments.run_all --repetitions 1 --output-root .tmp/ci-experiments
powershell -ExecutionPolicy Bypass -File scripts/环境/运行全部测试.ps1
```

需要重建 3 个领域 × 3 组画像的固定演示案例时，使用：

```powershell
.venv\Scripts\python.exe scripts/build_demo_cases.py --output <目标文件>
```

该脚本不会重建或写入已经取消维护的派生图谱目录。

## 5. 指标定义

- 接收精确率：被接收命题中，关系正确且证据充分的比例；
- 不支持命题接收率（UAR）：错误接收的不支持命题占全部金标准不支持命题的比例；
- Gold 召回：被接收的金标准支持命题占全部金标准支持命题的比例；
- 证据绑定完整率：被接收命题中至少绑定一个有效 `evidence_id` 的比例。该指标只检查结构绑定，不证明引用语义正确。

正式评测还应报告实体与关系 F1、ECE、Brier score、平均/P95 时延、成本和人工复核负担。

## 6. 结果边界

可以声称当前压力集和六组代理实验可重复运行，且异质三智能体在固定候选池上减少了错误接收。不能声称代理数据证明真实幻觉率下降、启发式 Idea 已通过新颖性验证，或本地规则耗时代表真实大模型时延。

正式 Track B 应使用开发阶段未见的冻结 PDF 测试集，由两名标注者独立判断实体、关系、方向和证据跨度，冲突交由第三人仲裁；压力集只承担回归职责，不能代替盲测。
