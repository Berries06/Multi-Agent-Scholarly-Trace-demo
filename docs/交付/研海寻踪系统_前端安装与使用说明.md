# 研海寻踪系统：前端安装与使用说明

> 适用系统：Windows 10/11（64 位）  
> 产品结构：React 18 + TypeScript + Vite 前端，FastAPI 后端  
> 前端地址：<http://127.0.0.1:5173/>  
> 后端地址：<http://127.0.0.1:8766/>  
> 接口文档：<http://127.0.0.1:8766/docs>

## 1. 运行前需要安装的软件

| 软件 | 要求 | 用途 | 检查命令 |
|---|---|---|---|
| Python | CPython 3.12.x，64 位 | FastAPI 后端及项目核心功能 | `py -3.12 --version` |
| Node.js | 20 或更高版本，64 位 | 运行 React/Vite 前端 | `node --version` |
| npm | 随 Node.js 一并安装 | 安装前端依赖 | `cmd /c npm --version` |
| 浏览器 | Edge、Chrome 等现代浏览器 | 使用网页工作台 | 浏览器“关于”页面 |
| 网络连接 | 首次安装依赖时需要 | 从 PyPI 和 npm 下载依赖 | 能访问软件包源 |

建议至少预留 4 GB 磁盘空间。项目只使用根目录下唯一的 Python 环境 `.venv`，不要另外创建 `.venv-lab` 等环境。

### 本机兼容说明

修订后的 `scripts\环境\创建统一环境.ps1` 不再只依赖 `py -3.12`。它会依次查找：

1. Windows Python Launcher 提供的 Python 3.12；
2. Codex 随附的 Python 3.12；
3. 用户目录中的 Python 3.12；
4. 用户目录中的 Python 3.13；
5. `PATH` 中版本不低于 3.12 的 `python`。

因此，本机即使没有注册 `py` 命令，也能使用已经存在的 Python 3.12.14 建立 `.venv`。

## 2. 项目依赖清单

### 2.1 后端基础依赖

- FastAPI：统一 REST API 与 SSE 流式接口；
- Uvicorn：ASGI 服务；
- python-multipart：表单与文件上传；
- pypdf：PDF 文本读取；
- jsonschema：结构化结果校验。

### 2.2 产品附加依赖

- httpx：HTTP 客户端与测试；
- PyQt6：桌面客户端；
- coverage：测试覆盖率；
- Streamlit 1.60.0：实验台；
- Pillow、python-docx：作品材料与文档处理；
- PyInstaller：桌面应用打包。

如需研究文档解析和实验跟踪，可额外安装 `docling` 与 `mlflow`；默认产品安装不包含这两项较大的研究工具。

### 2.3 前端依赖

- React 18、React DOM；
- TypeScript；
- Vite 5 与 React 插件；
- Ant Design 与图标库；
- ECharts、echarts-for-react；
- React/React DOM 类型定义。

依赖版本以根目录 `pyproject.toml` 和 `frontend\package-lock.json` 为唯一依据。

## 3. 最快启动方式

### 第一次使用

1. 将整个项目文件夹完整保留，不要只复制 `frontend` 文件夹。
2. 双击根目录的 `安装产品依赖.bat`。
3. 等待看到“统一环境已就绪”和“安装完成”。首次安装耗时取决于网络。
4. 如使用服务器免费 DeepSeek，在 `secret\DeepSeekAPI.txt` 中仅放入 API Key，不要加引号，也不要把该文件发送给他人。
5. 双击根目录的 `启动产品.bat`。
6. 浏览器通常会自动打开；若没有打开，手动访问 <http://127.0.0.1:5173/>。

### 以后使用

依赖成功安装一次后，通常只需双击 `启动产品.bat`，无需重复安装。

## 4. 管理员创建登录账号

系统关闭了公开注册，首次使用前需由管理员在项目根目录打开 PowerShell，执行：

```powershell
.\.venv\Scripts\python.exe .\scripts\后台创建用户.py --email member@example.com --nickname 研究员甲
```

按照终端提示输入密码。随后在网页登录页使用该邮箱和密码登录。不要把真实密码写进 Markdown、批处理文件或聊天记录。

## 5. 一键脚本说明

| 文件 | 作用 | 使用时机 |
|---|---|---|
| `安装产品依赖.bat` | 调用统一环境安装程序 | 第一次使用或依赖更新后 |
| `scripts\环境\创建统一环境.ps1` | 创建 `.venv`，安装 Python 与前端依赖 | 由安装批处理自动调用 |
| `启动产品.bat` | 同时启动 FastAPI 与 Vite，并打开网页 | 日常使用 |
| `scripts\环境\启动产品.ps1` | 检查端口、密钥和就绪状态后启动前后端 | 由启动批处理自动调用 |
| `scripts\环境\启动产品后端.ps1` | 仅启动 FastAPI 后端 | 前端开发或问题定位 |
| `scripts\环境\运行全部测试.ps1` | 运行 Python 编译检查与回归测试 | 交付验收 |
| `scripts\后台创建用户.py` | 后台创建登录账号 | 管理员首次配置账号 |

### 安装脚本的常用命令

标准安装（与双击安装批处理等效）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\环境\创建统一环境.ps1"
```

重建唯一环境：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\环境\创建统一环境.ps1" -Recreate
```

只安装 Python 依赖、跳过已经存在的前端依赖：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\环境\创建统一环境.ps1" -SkipFrontend
```

额外安装 Docling 与 MLflow 研究工具：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\scripts\环境\创建统一环境.ps1" -IncludeResearchTools
```

安装程序内部执行的核心依赖命令为：

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
.\.venv\Scripts\python.exe -m pip install --no-build-isolation -e ".[desktop,test,labs,package,submission]"
cd .\frontend
cmd /c npm ci
```

`--no-build-isolation` 用于避免 pip 再创建临时构建环境并重复下载 `setuptools`，可提升受限网络下的安装稳定性。

## 6. 手动启动方式

一键启动不可用时，可打开两个 PowerShell 窗口。

窗口一，在项目根目录启动后端：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\环境\启动产品后端.ps1
```

窗口二，在项目根目录启动前端：

```powershell
cd .\frontend
cmd /c npm run dev -- --host 127.0.0.1 --port 5173
```

看到 `Local: http://127.0.0.1:5173/` 后即可打开网页。Vite 会把前端的 `/api` 请求代理到 `127.0.0.1:8766`。

如暂时没有 DeepSeek Key，可用离线规则模式启动完整产品：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\scripts\环境\启动产品.ps1 -Provider mock
```

## 7. 安装与运行验收

在项目根目录依次执行：

```powershell
.\.venv\Scripts\python.exe --version
node --version
cmd /c npm --version
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8766/api/health
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8766/api/ready
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:5173/
```

验收标准：

- Python 版本不低于 3.12；
- Node.js 版本不低于 20；
- `/api/health` 返回 `status: ok`；
- `/api/ready` 显示资源就绪；
- 前端首页 HTTP 状态码为 200；
- 可以登录并进入研究工作台；
- 发起任务时能看到 SSE 推送的阶段进度。

## 8. 常见报错处理

### 8.1 `No runtime installed that matches 3.12`

旧安装程序只调用了 `py -3.12`。当前版本已经自动查找本机其他 Python 3.12+ 运行时。请重新双击修订后的 `安装产品依赖.bat`。若把项目复制到另一台电脑，仍需安装 64 位 Python 3.12，并在安装器中勾选 Python Launcher 或加入 `PATH`。

### 8.2 PyPI 出现 SSL、证书或连接重试

这表示依赖源连接不稳定，并非项目代码错误。确认系统时间正确、网络能访问 PyPI，并检查校园网、代理、VPN或安全软件。恢复网络后重新运行安装程序即可；不要使用关闭 TLS 校验的命令。

### 8.3 PowerShell 提示禁止运行 `npm.ps1`

不要直接输入 `npm`，改用：

```powershell
cmd /c npm ci
cmd /c npm run dev
```

项目安装程序已经采用这种调用方式。

### 8.4 提示缺少 DeepSeek Key

免费 DeepSeek 启动模式要求存在非空文件 `secret\DeepSeekAPI.txt`。配置 Key 后重启；仅做离线演示时，使用 `-Provider mock`。

### 8.5 端口 5173 或 8766 被占用

先查看占用进程：

```powershell
Get-NetTCPConnection -State Listen -LocalPort 5173,8766 | Select-Object LocalPort,OwningProcess
```

启动程序会自动替换能够确认属于研海寻踪的旧服务；若提示“unrecognized process”，请先保存对应程序中的工作，再关闭该占用进程，不要盲目结束全部 Python 或 Node 进程。

### 8.6 页面打不开或空白

1. 分别访问后端健康地址和前端地址；
2. 在浏览器按 `Ctrl+F5` 强制刷新；
3. 确认两个启动窗口都没有退出；
4. 确认 `frontend\node_modules\vite\bin\vite.js` 存在；
5. 缺少该文件时重新运行 `cmd /c npm ci`。

## 9. 安全注意事项

- 不要提交或转发 `secret\DeepSeekAPI.txt`；
- 用户自带 Key 只应在网页指定输入位置临时使用；
- 系统不提供公开注册，账号由管理员创建；
- 不要在截图、讲稿、报错记录中展示密码或 API Key；
- 迁移电脑时复制项目数据前，应确认其中不包含不应外发的密钥和个人数据。
